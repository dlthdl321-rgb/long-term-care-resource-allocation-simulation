# 분석 전 데이터 적합성 점검

점검일: 2026-07-23

## 결론

현재 데이터로 다음 분석은 가능하다.

- 현행 실질 시군구별 고령인구·장기요양 인정수요 규모 비교
- 서비스 유형별 기관 수·정원·신고 인력의 상대적 공급 부족 지역 탐색
- 취약수요 대리변수인 65세 이상 1인세대를 반영한 우선순위 비교
- 기관·정원·직종별 인력을 추가 배치했을 때 공급격차와 지역 형평성 지표가 얼마나 변하는지 모의실험

그러나 현재 자료만으로 실제 이용성과, 대기 해소, 비용효과 또는 인과효과를 예측할 수는 없다. 시뮬레이션 결과는 “추가 자원을 어디에 현장검증할 것인가”를 좁히는 정책 탐색 결과로 표현해야 한다.

## 핵심 품질 점검 결과

### 1. 수요자료

- 원자료의 5명 미만 값은 `*`로 비공개된다.
- 공개값만 합한 신청자는 1,582,784명이며 비공개 1,329셀을 반영한 범위는 1,584,113~1,588,100명이다.
- 공개값만 합한 인정자는 1,229,983명이며 비공개 18,446셀을 반영한 범위는 1,248,429~1,303,767명이다.
- 따라서 인정자 수는 단일값보다 하한·중앙·상한 민감도 분석을 권장한다.
- 235개 지역행 중 신청자 또는 인정자 공개값이 있는 현행 실질 지역은 229개다. `여주군`, `포천군` 등의 폐지 지역 0값 행은 분석에서 제외한다.
- 인구자료를 복합시의 일반구에서 시 단위로 재집계하면 현행 수요 229개 중 세종 표기 `_`를 제외한 228개가 자동 결합된다. 세종은 명시적으로 `세종특별자치시`에 대응시킨다.

### 2. 공급자료

- 시설 일반현황은 53,222행이지만 고유 기관은 약 3만 개이므로 행 수를 기관 수로 쓰면 안 된다.
- 정원자료는 43,581행·고유기관 29,153개이며 정원 결측은 25행이다.
- 인력자료는 50,312행·고유기관 30,578개다.
- 새 공급표는 지역×기관유형 키가 3,600개이며 중복키가 없다. 실제 소재지 기준 지역코드는 257개다.
- 기관 검색 API의 지역코드는 관할 코드로 추정되는 불일치 사례가 확인되었다. 따라서 지리 배치는 시설현황의 시도·시군구 코드와 주소를 사용했다.
- 방문요양·방문목욕처럼 정원 개념이 없는 서비스가 있어 정원 0을 결측이나 공급 0으로 단정하지 않는다. 이 유형은 기관 수와 신고 인력을 중심으로 비교한다.
- 기관이 여러 급여유형을 운영하면 동일 종사자가 유형별로 중복 신고됐을 수 있다. 서비스유형별 분석에는 사용할 수 있지만 모든 유형 인력을 단순 합산해 지역의 고유 종사자 수라고 부르지 않는다.

### 3. 지역코드

- 최신 법정동 코드에는 2026-06-30 생성된 `전남광주통합특별시` 3,204행이 포함되어 있다.
- 같은 기준월의 주민등록·장기요양 자료는 광주광역시와 전라남도를 별도로 사용한다.
- 최신 코드표를 그대로 마스터로 사용하면 시점 불일치가 발생하므로, 본 분석은 2025년 6월 SGIS 코드·경계와 각 원자료의 지역명을 기준으로 결합하고 최신 코드표는 개편 확인용으로만 사용한다.
- SGIS 코드, 주민등록 행정기관 코드, 법정동 코드, 장기요양 시설 코드는 서로 다른 체계다. 숫자를 직접 붙이지 않고 지역명과 출처별 대응표를 거친다.

### 4. 현원 표본과 평가자료

- 기관 상세 API에서 정원·남녀 현원·예약 인원을 받은 1,600건 표본이 있다.
- 이 표본은 시도별·유형별 순환선정 후 기관코드 순서의 앞쪽을 취한 자료이므로 확률표본이 아니다. API 필드와 가동률 산식을 검증하는 용도로만 사용하고 전국 또는 시군구 가동률 추정에는 쓰지 않는다.
- 추가로 2025-04-01 과거 시설별 현황에서 기관×유형별 정원·현원 34,083행을 확보했다. 22,461개 고유기관이며 과거 일반현황과 전부 결합된다.
- 입소·주야간·단기·치매전담 등 정원 기반 해석이 가능한 유형의 과거 전국 가중 현원/정원 비율은 약 79.42%다. 이는 2026년 현재 가동률이 아니라 시뮬레이션 민감도 범위를 정하는 과거 기준이다.
- 방문요양·방문목욕·방문간호·복지용구의 현원은 정원 대비 가동률로 해석하지 않는다.
- 평가자료는 평가연도가 2021~2025로 혼재한다. 서비스 유형별 평가주기가 달라 최신 평가등급을 동일시점 품질로 비교하면 안 된다.

## 추가 확보가 필요한 자료

우선순위는 다음과 같다.

1. **2026년 현재 기관별 현원·대기자·이용거절**: 과거 현원 전수와 현재 API 표본은 확보했지만 최신 전수 현원은 없다. 정원과 실제 여유공급을 구분하려면 상세 API의 전수 정기수집 또는 공단 제공신청이 필요하다.
2. **시군구×급여유형 실제 이용자 수**: 인정자를 잠재수요가 아니라 실제 이용수요와 미충족수요로 분해하려면 필요하다. 현재 확보한 공개파일은 전국 합계라 지역 분석에 사용할 수 없다.
3. **종사자 고유인원·FTE·이직률·구인난**: 신고 인력의 중복과 실제 근무가능시간을 보정하기 위해 필요하다. 공개 전수자료로 확인되지 않아 우선지역 기관조사가 필요하다.
4. **서비스별 이동시간·송영권역**: 특히 방문형·주야간보호의 실질 접근성을 계산하려면 필요하다. 주소와 경계는 확보했으므로 우선지역 선정 후 도로망 API 또는 현장 송영자료를 결합한다.
5. **지역별 신설·증원비용과 운영예산**: 비용제약 최적화에 필요하다. 현재는 사용자 입력 범위에 따른 민감도 분석으로 처리한다.

## 권장 분석 순서

1. 229개 현행 수요지역을 기준으로 복합시 일반구 인구·가구·공급을 시 단위로 집계한다.
2. 신청자·인정자는 하한·중앙·상한 세 시나리오를 만든다.
3. 입소형은 인정자 대비 정원·요양보호사, 방문형은 인정자 대비 기관 수·신고 인력, 주야간보호는 정원·기관·인력을 함께 계산한다.
4. 전국 또는 동일 시도 내 분위수로 상대적 취약지역을 선별한다.
5. 기관 1개, 정원 10명, 요양보호사 5명 등 단위 자원을 추가하여 격차·형평성 지표 변화를 비교한다.
6. 결과는 확정 배치안이 아니라 현원·대기·구인난을 확인할 우선 현장조사 목록으로 제시한다.
