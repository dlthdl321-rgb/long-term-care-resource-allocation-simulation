# 데이터와 분석 재현자료

이 폴더에는 연구 데이터와 분석을 다시 실행하는 데 필요한 자료를 함께 보관합니다.

| 경로 | 내용 |
| --- | --- |
| [`data/`](data/) | 분석용·전처리 데이터와 정책 보완자료 |
| [`src/`](src/) | 수집·전처리·품질검사·통계·시뮬레이션 코드 |
| [`config/`](config/) | 통계분석 설정 |
| [`metadata/`](metadata/) | 출처, 기준일, 데이터 품질과 분석 준비도 |
| [`outputs/`](outputs/) | 기술통계·추론통계·시뮬레이션·검증 결과 |

Python 코드는 이 폴더를 실행 기준 경로로 인식합니다. 저장소 최상위에서 실행할 때는 `python "03_데이터/src/파일명.py"` 형식을 사용합니다.
