# 통계 분석 실행 전 확정안

## 1. 분석 원칙

- 전국 행정자료이므로 기술통계·효과크기·민감도 분석을 우선한다.
- p값은 탐색적으로만 사용하고 인과관계의 근거로 사용하지 않는다.
- 평균과 함께 중앙값·사분위수·범위·표준편차를 제시한다.
- 인정자 비공개값은 하한·중앙·상한 세 조건으로 계산한다.
- 하위 20%·25%·30% 기준에서 후보 순위가 유지되는지 확인한다.
- 서비스별 반복검정에는 Benjamini-Hochberg FDR 보정을 적용한다.
- 부트스트랩과 모의실험은 난수 시드 `20260723`을 사용한다.

## 2. 기술통계

| 대상 | 계산 |
| --- | --- |
| 데이터 품질 | 행·열·결측·중복·고유키·결합률 |
| 수치형 변수 | 유효값, 평균, 중앙값, 최소·최대, 범위, Q1·Q3, IQR, 표준편차 |
| 범주형 변수 | 빈도, 비율, 최빈값 |
| 날짜형 변수 | 최초·최종 기준일, 기간, 공개간격 |
| 식별자 | 고유 개수, 중복키 |
| 지역×서비스 지표 | 분포, 공급 0 지역, IQR 이상치, 지니·Theil |

## 3. 가설별 통계 준비

### 가설 A

수요 증가율과 인정자 1,000명당 기관 수의 관계를
Spearman 순위상관으로 탐색한다.

- 최소 완전 관측쌍: 30개
- 공급 0 지역도 기관 수 0으로 포함
- 보고: 상관계수, 완전 관측 수, 보정 전·후 p값, 해석 제한
- 인과 표현: 금지

### 가설 B

기관 수가 비슷한 지역에서 정원·신고인력 분포가 추가 정보를 제공하는지
서비스별 기술통계와 순위상관으로 확인한다.

- 정원은 `사용가능` 서비스만 분석
- 신고인력은 고유 FTE가 아니라 대리지표로 표시
- 동률이 많거나 희소한 유형은 통계검정보다 분포를 우선
- 공급지표 동률이 50%를 초과하는 서비스는 순위검정에서 제외
- 수요 하한·상한 순위상관이 0.95 미만이면 세 수요 조건을 별도로 보고

### 가설 C

같은 추가 자원에서 균등·수요비례·취약지역 우선·형평성 탐욕 기준의
공급률과 형평성 변화를 비교한다.

- 총자원 보존 필수
- 비교지표: 평균·중앙·최저 공급률, 공급 0 지역 수, 지니, Theil
- 현재 방식은 현실 최적화가 아니라 조건부 모의실험

## 4. 통계 실행 중단 기준

- 분석지역이 229개와 불일치
- 지역×서비스 중복키 발생
- 집계 전후 기관·정원·인력 합계 불일치
- 핵심 분모가 0 이하
- 무한값 발생
- 서비스별 핵심지표 분산이 0
- 완전 관측쌍이 30개 미만인 서비스는 해당 추론통계에서 제외

## 5. 아직 실행하지 않는 분석

- 실제 미충족수요 추정
- 최신 가동률 분석
- 비용효과 분석
- 이동시간 접근성 분석
- 대기·이용거절·가족부담에 대한 인과효과
- 현실 제약을 포함한 최적 자원배치
