# 선행연구 검토: 노인의료복지시설의 지역별 수요 대비 공급 적정성

## 1. 핵심 선행연구

### 서지정보

- 김세진·김혜수(2021), 「노인의료복지시설의 지역별 수요 대비 공급의 적정성 분석: 시·군·구를 중심으로」
- 학술지: 『GRI연구논총』, 23권 4호, 77–104쪽
- 발행기관: 경기연구원
- DOI: [10.23286/gri.2021.23.4.004](https://doi.org/10.23286/gri.2021.23.4.004)
- [KCI 공식 상세페이지·원문 내려받기](https://www.kci.go.kr/kciportal/landing/article.kci?arti_id=ART002784359)
- [DBpia 상세페이지](https://www.dbpia.co.kr/journal/articleDetail?nodeId=NODE11147114)

### 연구 목적

전국 시군구별 노인의료복지시설의 수요 대비 공급이 적정한지 분석하고, 시설 이용 기회의 지역 간 균등성을 높이기 위한 정책적 대응방안을 제시하는 연구다.

### 사용 자료

| 구분 | 자료 | 제공기관 | 활용 |
| --- | --- | --- | --- |
| 잠재수요 | 주민등록인구 | 행정안전부 | 지역별 노인인구 기반 수요 |
| 현재수요 | 장기요양 등급판정 현황 | 국민건강보험공단 | 인정자 기반 수요 |
| 공급 | 장기요양기관 현황 | 국민건강보험공단 | 노인의료복지시설 정원 |
| 공간자료 | 시군구 경계 | 공간통계 자료 | 지역 간 공간관계 분석 |

### 수요·공급 시나리오

연구는 수요 정의에 따라 결과가 달라질 수 있다는 점을 반영해 세 가지 수요 시나리오를 비교했다.

1. 65세 이상 노인인구를 수요로 보는 시나리오
2. 85세 이상 노인인구를 수요로 보는 시나리오
3. 장기요양 1–3등급 인정자를 수요로 보는 시나리오

각 수요 시나리오에서 공급은 ① 노인의료복지시설 수와 ② 노인의료복지시설 정원 수로 나누어 비교했다. 공간상관성 분석에서는 시군구별 `정원 1인당 수요`를 사용했다. 이 값이 클수록 해당 지역의 수요 대비 공급이 상대적으로 적다는 의미다.

### 분석방법

| 방법 | 확인하는 내용 | 현재 연구에 적용할 부분 |
| --- | --- | --- |
| Coulter 비형평계수 | 수요 비중과 공급 비중의 지역 간 불일치 | 지니계수보다 수요–공급 대응성을 직접 평가하는 핵심 지표 후보 |
| Global Moran’s I | 수요 대비 공급 수준이 인접 지역끼리 공간적으로 군집하는지 | 시군구 인접행렬을 이용한 전국 공간 자기상관 검정 |
| LISA·공간분석 | 고수요·저공급 등의 국지적 군집 위치 | 현장확인 우선지역의 공간 군집 지도 |
| 충족도 | 지역별 수요에 비해 정원이 어느 정도 확보됐는지 | 공급 부족·과잉의 시나리오별 민감도 비교 |
| GeoDa·QGIS 3.16 | 공간통계와 지도화 | Python의 `geopandas`·`libpysal`·`esda`로 재현 가능 |

### 주요 결과

- 도 지역보다 광역시에서 전반적인 비형평 수준이 높았다.
- 광역시·도의 중심도시와 도서산간지역에서는 공급 부족이, 중심도시 외곽에서는 공급 과잉이 나타나는 경향이 있었다.
- 세 가지 수요 시나리오 모두에서 정원 1인당 수요가 공간적 자기상관성을 보였다.
- 전국 총량으로는 과잉공급처럼 나타나더라도 시군구별 차이가 컸다.
- 따라서 전국 평균이나 총량만으로 적정성을 판단하지 말고 시·구와 군의 특성을 구분한 장기 수급계획이 필요하다고 제안했다.

## 2. 현재 연구와의 관계

### 공통점

- 전국 시군구를 분석 단위로 사용한다.
- 노인인구·장기요양 인정수요와 시설공급을 결합한다.
- 지역 간 형평성과 수요 대비 공급격차를 분석한다.
- 공급 부족을 단순 기관 수가 아니라 정원과 결합해 해석한다.

### 차별화할 수 있는 부분

| 핵심 선행연구 | 현재 연구의 확장 |
| --- | --- |
| 노인의료복지시설 정원 중심 | 시설급여뿐 아니라 재가급여를 포함한 39개 서비스의 기관·정원·직종별 인력 비교 |
| 단면적 적정성 분석 | 2010–2024년 공급·인력, 2013–2024년 실제 이용 패널과 2026년 최신 단면 결합 |
| 세 가지 수요 시나리오 | 인정자 추정 하한·중앙·상한과 65세·75세·85세 이상 인구 및 고령 1인세대 민감도 |
| 형평성·공간상관성·충족도 진단 | 제한된 추가 자원의 균등·수요비례·취약지역 우선·형평성 최소화 배치 시뮬레이션 |
| 공급 적정성 진단 | 배치 전후 공급률·최저 공급률·공급 0 지역·IQR·Coulter 비형평계수 변화 비교 |
| 실제 이용·가동 제약 제한 | 급여 이용자·제공일수·급여비와 시설급여 A03·A04 최신 정원·현원 결합 |

### 연구 설계에 반영할 사항

1. 지니계수만 사용하지 않고 Coulter 비형평계수를 추가한다.
2. 수요를 하나로 고정하지 않고 노인인구·인정자·시설급여 대상 가능 집단으로 나누어 민감도를 계산한다.
3. Global Moran’s I와 LISA를 이용해 공간적 군집을 검정한다.
4. 시·구와 군을 분리하거나 지역유형을 통제해 같은 기준의 기계적 비교를 피한다.
5. 공급은 기관 수 외에 정원·현원·직종별 인력으로 구분한다.
6. 적정성 진단과 자원배치 시뮬레이션을 구분하고, 실제 미충족 수요나 인과효과라고 표현하지 않는다.

## 4. 선행연구 검토를 반영한 연구 공백

기존 연구는 지역별 수요 대비 시설 정원의 형평성과 공간적 군집을 잘 보여주지만, 제한된 추가 자원을 어느 지역에 배치할 때 공급격차가 어떻게 달라지는지를 여러 배치규칙으로 비교하는 단계는 상대적으로 부족하다. 현재 연구는 다음 연구 공백을 다룬다.

> 전국 시군구별 장기요양 수요와 서비스별 기관·정원·인력·실제 이용을 결합해 공급 병목을 구분하고, 동일한 추가 자원을 서로 다른 규칙으로 배치했을 때 수요 대비 공급률과 지역 형평성이 어떻게 변화하는지를 재현 가능한 시뮬레이션으로 비교한다.

단, 이는 공급지표의 조건부 변화를 계산하는 연구이며 실제 대기자 감소, 입원 감소 또는 삶의 질 개선의 인과효과를 직접 추정하는 연구는 아니다.
