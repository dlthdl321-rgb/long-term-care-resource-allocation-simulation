# 선행연구·제도 참고자료

이 폴더는 장기요양 공급지표, 수요·공급 적정성 논의와 제도적 단위를 이해하기 위해 검토한 참고자료를 보존합니다. 분석설계의 배경 근거이며 현재 대표 결과를 직접 생성한 산출물은 아닙니다.

- `선행연구_노인의료복지시설_수요공급_적정성.md`: 연구 질문·지표 설계에 참고한 요약
- `선행연구_서지정보.bib`: 인용 문헌의 서지정보
- `ltci_benefit_cost_standard_20260101.html`: 분석 당시 확인한 장기요양 급여비용 기준 공개페이지 스냅숏

저작권이 있는 원문 전체는 저장하지 않고 서지정보와 분석에 필요한 공개 제도자료만 관리합니다. 대표 분석의 정확한 데이터·방법·코드는 각각 `03_데이터/`, `02_분석보고서/01_분석방법론.md`, `04_분석코드/`를 따릅니다.
