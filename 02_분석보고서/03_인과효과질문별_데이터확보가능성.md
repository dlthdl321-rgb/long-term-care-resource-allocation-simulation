# 인과효과 질문별 자료 확보 가능성

기준일: 2026-07-23

## 결론

요청한 여섯 질문을 모두 전국 시군구 공개 집계자료만으로 직접 검증할 수는 없다.

- 공개자료로 직접 분석 가능: 서비스별 이용자·제공일수·급여비, 연간 시설급여 이용자 변화
- 공개자료로 대체지표 분석 가능: 인정자 대비 급여 이용 격차, 지역 전체 입원 이용, 지역 건강·삶의 질
- 승인형 개인자료가 필요한 질문: 실제 대기 감소, 개인 서비스 이용률, 서비스 이용자의 입원·응급실·건강·삶의 질 변화, 서비스 유형 간 개인 수준 비교효과
- 정기 공개자료가 확인되지 않은 질문: 전국 시군구별 실제 대기자와 미충족 수요

## 질문별 판정

| 질문 | 직접 측정에 필요한 자료 | 공개 수집 판정 | 현재 확보·가능한 대체지표 | 해석 한계 |
|---|---|---|---|---|
| 기관 1곳 추가 시 실제 대기자 감소 | 기관별 월별 대기 등록·입소·취소·중복 식별 | 불가 | 정원·현원·시설급여 이용자 | 빈 병상과 대기자는 다른 개념 |
| 인력 추가 시 서비스 이용률 증가 | 기관별 월별 직종별 FTE와 인정자별 이용 여부 | 조건부 | KOSIS 인력 연간표+급여 이용자 | KOSIS API 키 필요, 개인 이용확률 아님 |
| 서비스 확충 시 입원·응급실·시설입소 감소 | 동일인의 장기요양 이용과 의료청구·입소 시작일 | 승인형 자료 필요 | 지역별 입원 이용과 연간 시설급여 이용자 | 생태학적 분석이며 개인 효과가 아님 |
| 건강·삶의 질·학대 위험 개선 | 동일인의 전후 건강·삶의 질·학대 결과 | 대부분 승인형/별도 연계 | 지역사회건강조사, 지역별 학대 신고 | 서비스 이용자만의 결과가 아니고 신고량은 발생량과 다름 |
| 서비스 유형별 효과 비교 | 개인별 서비스 유형·시작일·결과·교란변수 | 승인형 자료 필요 | 시군구 서비스별 이용자·일수·비용 | 지역 평균 비교만 가능 |
| 실제 미충족 수요 인원 | 인정자의 필요 서비스·희망·미이용 사유·대기 여부 | 불가 | 인정자 수와 급여 이용자 수의 격차 | 두 자료의 기준기간과 중복 구조가 달라 실제 인원으로 단정 불가 |

## 이번에 생성한 공개 결과자료

### 시군구별 재가·시설급여 결과 패널

- 기간: 2013~2024년
- 행 수: 2,994
- 지역코드: 254개
- 연도×지역 중복: 0건
- 변수:
  - 전체 고유 급여 이용수급자
  - 재가서비스별 이용자 합계와 제공일수
  - 시설서비스별 이용자 합계와 제공일수
  - 재가·시설 급여제공기관 수
  - 시설급여 이용자 비중 대체지표

주의:

- 서비스별 이용자는 서비스 사이에 중복될 수 있다.
- 시설급여 이용자는 해당 연도 이용자이며 신규 입소자가 아니다.
- 시설급여 이용자 비중은 시설입소 발생률이 아니라 대체지표다.

## 추가로 신청 가능한 자료

### 1. 국민건강보험공단 맞춤형 연구DB

권장 대상:

- 장기요양 인정·등급·유효기간
- 장기요양 급여내역과 서비스 시작일
- 기관기호와 급여종류
- 의료기관 입원·외래·응급실 청구
- 시설급여 시작일
- 사망·자격·주소지

이 자료가 승인되면 동일인의 서비스 이용 전후 입원·응급실·시설입소를 분석할 수 있다.

```text
월 이용일수
기관ID
입원일수
입원건수

시설입소시작일

```

### 2. 질병관리청 지역사회건강조사 원시자료

- 2008년 이후 매년 조사
- 시군구별 표본 약 900명
- 건강행태·질환·삶의 질·의료이용 변수 제공
- 자료이용계획서 심의 후 승인되며 공식 안내상 평균 2~3업무일 소요

활용 범위:

- 지역 차원의 주관적 건강·삶의 질·미충족 의료 변화
- 서비스 공급이 증가한 지역과 비교지역의 건강지표 추세 비교

한계:

- 조사대상 전체 지역주민 자료이므로 장기요양서비스 이용자 효과를 직접 식별하지 못한다.
- 개인 단위 장기요양 이용내역과 연결되지 않는다.

### 3. KOSIS API 자료

API 키 확보 후 우선 수집 대상:

| 표 ID | 내용 | 활용 |
|---|---|---|
| `DT_35006_N021` | 시군구별 급여종류별 기관 수·정원 | 자원 추가 시점과 공급능력 |
| `DT_35006_N022` | 시군구별 장기요양기관 인력 | 직종별 인력 증가 |
| `TX_35003_A027` 등 4개 권역표 | 시군구별 관내 입원 진료 | 지역 입원 결과 |
| `TX_35003_A030` 등 4개 권역표 | 시군구별 관외 입원 진료 | 거주지역 밖 입원 결과 |
| `DT_117075_HEALTH_EQ_5D` | 시군구별 EQ-5D, 2008~2019 | 삶의 질 대체 결과 |

KOSIS 지역별 의료이용통계는 2006~2024년의 시군구별 관내·관외 입원 진료표를 제공하지만 자동 수집에는 KOSIS API 키가 필요하다.

## 별도 행정자료가 필요한 항목

### 대기자

지자체 또는 기관에 다음 집계자료를 요청해야 한다.

```text
기관ID
서비스유형
기준월
정원
현원
신규대기등록
월말대기자
입소·서비스개시
대기취소
사망·전출
중복대기 식별규칙
대기일수 중앙값
```

### 미충족 수요

인정자 또는 이용지원 상담자료에 다음 항목이 필요하다.

```text
익명개인ID
인정일
필요서비스
희망서비스
실제이용서비스
미이용 여부
미이용 사유
대기 여부
가족돌봄 여부
비용부담
거리·교통 문제
서비스 거절 여부
```

### 학대 위험

노인보호전문기관 사례자료에는 다음 연결 변수가 필요하다.

```text
익명사례ID
발생월
거주 시군구
사례판정
학대유형
위험도
재학대 여부
장기요양 이용 여부
서비스유형
서비스 시작일
```

공개된 학대 신고자료는 일부 지역 또는 시도 수준이며, 신고 증가가 실제 학대 증가인지 인식·신고 접근성 향상인지 구분할 수 없다.

## 분석 단계 권고

1. 공개 패널로 서비스 공급 증가와 급여 이용·시설급여 이용 변화를 분석한다.
2. KOSIS API 키로 기관 정원·인력·입원 결과를 보완한다.
3. 지역사회건강조사 승인자료로 지역 건강·삶의 질 변화의 보조 결과를 분석한다.
4. 논문에서 개인 인과효과를 주장하려면 NHIS 맞춤형 연구DB를 신청한다.
5. 대기자·미충족 수요는 연구대상 지자체와 기관의 행정자료 협조가 필요하다.
