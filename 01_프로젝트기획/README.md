# 도 소속 농촌 군의 장기요양 자원부족 진단과 자원변경·재배치 시뮬레이션

> 이 문서는 프로젝트의 전체 연구 흐름과 문서별 역할을 안내한다.

> **문서 상태: 계획 단계 기록.** 이 폴더에는 분석 시작 전 문제정의·가설·초기 설계가 남아 있습니다. 실제 수행한 최종 방법과 해석 기준은 [현재 분석방법론](../02_분석보고서/01_분석방법론.md)을 우선합니다.

이 프로젝트는 도 소속 군의 공통 잠재수요 대비 기관·핵심인력·정원 공급수준과 상대적 자원부족을 진단하고, 취약성·수요압력·공급공백·접근성을 고려한 현장검토 시급지역을 제시한다. 사용자가 자원을 추가·감축·이전·재배치하거나 같은 총량을 자동배치했을 때 지역별 공급격차, 최소서비스 기반, 지원 시급성과 지역격차의 직접·간접 계산상 변화를 비교한다.

Q5-B는 동일 조건에서 `어디에 배치할지` 비교한다. 기관은 수요비례·부족량·기관 미관측·지역취약성·지원 시급성 5개 전략, 핵심인력·정원은 기관 미관측을 제외한 4개 전략을 비교한다. Q5-C는 `무엇을 배치할지` 선택하는 별도 조건부 시나리오다.

본 연구에서 `농촌 군`은 국가의 공식 농촌 분류가 아니라 행정구역명이 군이고 시도명이 도로 끝나는 76개 군을 뜻하는 조작적 정의다. 광역시 소속 6개 군은 행정·재정·서비스 환경의 차이를 줄이기 위해 주분석에서 제외하고 민감도 분석 대상으로 둔다.

장기요양 인정자 수는 세 서비스를 비교하기 위한 공통 잠재수요 분모이며, 모든 인정자가 방문요양·방문간호·주야간보호를 동일하게 필요로 한다는 뜻은 아니다. 본 연구의 목표기준은 공식 부족 또는 적정 기준이 아니라 전략 간 결과를 비교하기 위한 탐색적 시뮬레이션 기준이다.

## 연구 흐름

```text
76개 군과 접근범위 설정
→ 내부·유효공급 기준선
→ 목표충족률·상대부족도·부족자원 순위
→ 취약성·수요압력·접근공백 기반 시급성
→ 수동 추가·감축·이전·스트레스 테스트
→ 자동 배치전략 비교
→ 직접·간접 개선·악화와 현장검토 지역
```

## 핵심 의사결정 질문

Q1 현재 공급과 상대부족, Q2 기관–제공역량, Q3 지역특성, Q4 지원 시급지역, Q5-A 수동 변경, Q5-B 자동 배치, Q5-C 자원유형 선택의 순서로 분석한다. 상세 문장은 [분석기획](03_분석기획.md)을 따른다.

## 핵심 용어

| 용어 | 정의 |
| --- | --- |
| 공급수준 | 서비스 수요 1,000명당 기관·핵심인력·정원 등 현재 공급량 |
| 공급부족 | 현재 공급량이 설정한 탐색적 목표 공급량에 미달한 상태 |
| 연속형 공급격차 | 탐색 목표 공급량과 현재 공급량의 0 이상 차이 |
| 정수형 추가 필요량 | 탐색 목표 공급량을 올림한 뒤 현재 공급량을 뺀 0 이상의 정수형 자원 수량 |
| 부족의 구성 | 공급부족이 기관·핵심인력·주야간보호 정원 중 어디에서 나타나는지 구분한 결과 |
| 공급제약 가능성 | 기관 공급수준에 비해 인력·정원 등이 상대적으로 낮아 서비스 제공을 제한할 수 있는 상태 |
| 추가 자원 | 시뮬레이션에서 새로 배치하는 기관·인력 또는 정원 단위 |
| 배치전략 | 정해진 총량의 추가 자원을 지역과 서비스에 배분하는 규칙 |
| 시뮬레이션 효과 | 배치 후 총 추가 필요량·목표 미달지역 수·기관 미관측지역 수·하위 10% 공급수준·지역격차의 계산상 변화 |
| 우선 검토지역 | 분석결과상 현장확인과 사업검토가 먼저 필요한 지역으로, 설치 확정지역은 아님 |
| 상대 자원부족도 | 목표충족률을 1에서 뺀 0~1 척도 |
| 유효공급 | 지역 내부 공급과 선택한 접근범위의 가중 외부공급 합계 |
| 완전 접근공백 | 내부 및 설정 접근범위에서 공급기반을 확인하지 못한 상태 |
| 지원 시급성 | 취약성·수요압력·접근성 반영 부족·접근성 불리·완전 공백의 탐색용 종합점수 |
| 직접·간접 영향 | 변경지역 자체와 그 자원을 접근 가능 공급으로 사용하던 다른 지역의 변화 |

총 추가 필요량은 동일한 서비스×자원유형 시나리오 안에서만 지역별 정수형 추가 필요량을 합산한다. 방문요양기관·방문요양 요양보호사·방문간호기관·방문간호 간호인력·주야간보호기관·주야간보호 요양보호사·주야간보호 정원은 각각 별도 지표이며, 기관 수·인력 수·정원 수를 더한 종합 총량은 산출하지 않는다. 전략별 공급부족 개선량과 자원 1단위당 부족량 감소도 같은 서비스×자원유형 안에서만 계산한다.

## 최종 산출물

- 군×서비스×자원유형 공급수준·추가 필요량 진단표

- 기준선 대비 성과지표 변화
- 부족 구성·공급제약 가능성 보조 진단표
- 현장확인 우선 지역 목록
- 추가 자원 총량·목표기준·지역범위·배치상한 민감도 분석
- 수동 추가·감축·이전 시나리오 전후표와 저장 메타데이터

- 부족자원 순위와 지원 시급지역 순위·안정성
- 완전 접근공백과 접근성으로 완화된 공급격차
