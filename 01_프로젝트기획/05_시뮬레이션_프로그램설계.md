# 지역별 노인장기요양 자원 의사결정 시뮬레이터 설계

> **문서 상태: 계획 단계의 제품·프로그램 설계 기록.** 현재 구현된 분석 규칙과 해석은 [분석방법론](../02_분석보고서/01_분석방법론.md)을 우선합니다.

> 문서 상태: 프로그램 기능·데이터·화면·검증을 정의한 설계안이다. 현재 구현 범위는 도 소속 76개 군의 방문간호기관 자동배치 MVP이며, 수동 변경·지원 시급성·UI·공간 접근성은 단계별 확장 범위다.

## 1. 목적과 핵심 질문

이 프로그램은 최적 입지를 확정하는 도구가 아니라 다음 세 기능을 수행하는 재현 가능한 정책 시뮬레이터다.

1. 지역별 서비스·자원의 상대적 부족 진단
2. 자원 추가·감축·이전·순증 배치에 따른 공급격차와 지역격차의 계산상 변화 비교
3. 고령화·고령 1인세대·장기요양 수요·공급공백을 구분해 현장검토 우선지역과 부족자원 제시

| 질문 | 내용 |
| --- | --- |
| 진단 | 공통 잠재수요 대비 서비스별 기관·핵심인력·정원 공급수준과 상대적 부족은 어느 정도인가? |
| 시뮬레이션 | 자원을 추가·삭제·이전하면 지역별·전체 공급격차, 목표 미달지역과 지역격차가 어떻게 변하는가? |
| 정책 | 취약성·수요압력·공급공백을 고려할 때 어디에서 어떤 자원을 우선 현장검토해야 하는가? |

계산 결과는 설치·폐쇄 권고나 정책 인과효과가 아니다.

## 2. 범위

- 주분석: 도 소속 76개 군
- 지역범위 민감도: 광역시 소속 군을 포함한 82개 군
- 서비스: 방문요양·방문간호·주야간보호
- 자원: 기관·핵심인력·주야간보호 정원
- 대표 MVP: 방문간호기관 추가·삭제·이전 및 기관 5개 자동배치

기관·인력·정원은 단위가 다르므로 실제 공급량과 배치효과를 합산하지 않는다. 여러 자원의 상대부족을 결합한 점수는 현장검토 순위 탐색에만 사용한다.

## 5. 수요·공급·필요량

주분석은 세 서비스에 동일한 인정자 기반 공통 잠재수요를 적용한다.

```text
D_is = D_i
R_isr = S_isr / D_is × 1,000
M_isr = T_sr × D_is / 1,000
C_isr = max(0, M_isr - S_isr)
G_isr = max(0, ceil(M_isr) - S_isr)
```

- `R`: 수요 1,000명당 공급수준
- `M`: 목표 공급량
- `C`: 연속형 공급격차
- `G`: 정수형 추가 필요량

| 서비스 | 기관 | 핵심인력 | 정원 |
| --- | --- | --- | --- |
| 방문요양 | 방문요양기관 | 요양보호사 | 미적용 |
| 방문간호 | 방문간호기관 | 간호사+간호조무사 | 미적용 |
| 주야간보호 | 주야간보호기관 | 요양보호사 | 이용정원 |

수요 민감도는 인정자 하한·중앙·상한, 65세·85세 이상 인구, 서비스별 이용·필요비율을 지원한다. 목표는 배치 전 제1사분위수·중앙값, 전국 참고값 또는 사용자 정책입력값을 고정해 사용하며 공식 적정기준으로 표현하지 않는다.

## 6. 상대 자원부족도

원 단위가 다른 자원을 비교할 때는 목표충족률과 상대부족도를 사용한다.

```text
A_isr = min(1, R_isr / T_sr)
L_isr = 1 - A_isr
```

- `L=0`: 목표 충족
- `L=1`: 공급 없음

지역 내부에서 `L`을 내림차순으로 정렬해 부족자원 1·2·3순위를 표시한다. 기관 수가 0이면 `공급기반 미관측`을 선행 상태로 두고, 기관 부재로 인력·정원이 0인 상황을 독립적인 복합 부족으로 중복 계산하지 않는다.

권장 상태는 `공급기반 미관측 → 목표대비 심각한 부족 → 부족 → 목표근접 → 목표충족`이다.

## 7. 취약성과 지원 시급성

개별 취약성 지표는 고령화율, 85세 이상 비율, 고령 1인세대 부담, 인정자 비율, 인정수요 증가율이다. 고령 1인세대 부담은 개인 단위 독거율이 아닌 주민등록 세대 기반 대리지표다.

```text
V_i =
0.20×Z(고령화율)
+ 0.20×Z(85세 이상 비율)
+ 0.20×Z(고령 1인세대 부담)
+ 0.25×Z(인정자 비율)
+ 0.15×Z(인정수요 증가율)
```

기본 가중치는 사용자 변경이 가능해야 하며 개별 지표와 종합점수를 함께 표시한다.

지원 시급성은 취약성 자체가 아니라 수요압력·취약성·공급부족·최소서비스 공백의 결합이다.

```text
수요압력 D*_i = 0.6×P(인정자 규모) + 0.4×P(인정자 증가율)
공급부족 L*_i = Σ α_sr×L_isr
지원 시급성 U_i = 0.30×V_i + 0.25×D*_i + 0.35×L*_i + 0.10×Z_i
```

`P`는 0~100 분위점수, `Z_i`는 기관 미관측 등 최소서비스 공백점수다. 통합점수는 우선순위 탐색용이며 실제 배치 판단에는 구성요소를 반드시 병렬 표시한다.

| 유형 | 해석 |
| --- | --- |
| 고취약·고부족 | 최우선 현장검토 |
| 저취약·고부족 | 공급확충 중심 검토 |
| 고취약·저부족 | 이용·연계·예방 지원 검토 |
| 저취약·저부족 | 정기 모니터링 |

## 8. 사용자 시나리오

| 유형 | 규칙 |
| --- | --- |
| 추가 | 특정 지역의 기관·인력·정원을 증가 |
| 삭제·감축 | 폐업·인력유출·정원축소 스트레스 테스트 |
| 이전 | 한 지역에서 감소하고 다른 지역에 동일 자원을 증가, `ΣΔS=0` |
| 순증 배치 | 서비스×자원별 총량 `B_sr`을 여러 지역에 배치, `ΣΔS=B_sr` |

수동 시나리오는 지역·서비스·자원·변경량을 직접 입력한다. 자동 시나리오는 수요비례·공급부족량·기관 미관측·취약성·지원 시급성·사용자 가중치 전략을 지원한다.

## 9. 제약과 상태 갱신

```text
S_after = S_before + ΔS
S_after ≥ 0
```

- 기관·인력·정원은 정수
- 필요량과 배치상한 적용
- 총량고정 모드에서 변경량 합계 0
- 순증 모드에서 변경량 합계가 입력 총량과 일치
- 기관 없는 지역에 인력 단독 배치 금지
- 주야간보호기관 없는 지역에 정원 단독 증가 금지
- 목표기준은 실행 중 재계산하지 않음
- 모든 비교전략은 동일 기준선·목표·총량·상한 사용

기관 삭제 후 관련 인력·정원은 공개 집계자료만으로 귀속을 특정할 수 없으므로 초기 버전에서는 자동 삭제하지 않고 불일치 경고를 표시한다.

실행 후 공급량·공급수준·연속형 격차·정수형 필요량·목표 미달·기관 미관측·상대부족도·부족자원 순위·시급성 점수와 순위를 다시 계산한다.

## 10. 성과평가

| 정책목표 | 지표 |
| --- | --- |
| 효율성 | 총 연속형 격차 감소, 단위당 격차 감소, 수혜 잠재수요 |
| 최소보장 | 기관 미관측·목표 미달 감소, 최저·하위 10% 증가 |
| 형평성 | 제1사분위수 증가, IQR·Gini 감소, 하위-중앙 격차 |
| 안전성 | 악화지역·미개선지역·미배치 자원, 총량 보존 |

단일 종합순위보다 정책목표별 트레이드오프를 보여준다. 화면에는 “예상 이용자 증가”가 아니라 “잠재수요 대비 공급수준의 계산상 변화”라고 표시한다.

## 11. 화면

1. **전국·지역 현황:** 범위·지역·서비스·자원·수요·목표 필터, 기관 미관측·목표 미달·총 격차·시급지역 카드와 지도
2. **지역 상세:** 인구·수요·공급·목표·격차·필요량·상대부족도·부족순위와 근거 요약
3. **수동 편집:** 지역별 현재·변경·변경후 표, 추가·초기화·실행·저장·CSV 다운로드와 제약 경고
4. **자동 전략 비교:** 서비스·자원·총량·상한·목표·전략·가중치 입력과 성과표·배치지도
5. **전후 영향:** 지역별 개선·악화와 전체 공급격차·미달·미관측·하위 10%·Gini 비교
6. **민감도:** 수요·목표·총량·상한·가중치·지역범위에 따른 평균순위·1위/상위2위 비율·배치지역 일치율

초기 UI는 Streamlit으로 구현하고 지도는 데이터 가용성에 따라 Plotly choropleth 또는 GeoPandas를 사용한다.

## 13. 자동 검증과 테스트

필수 불변조건:

```text
모든 자원량 ≥ 0
모든 자원량은 정수
배치후 = 배치전 + 변경량
총량고정: ΣΔS = 0
순증: ΣΔS = B_sr
기관 없는 지역에 인력·정원 단독 증가 금지
고정 목표와 공통 기준선 사용
```

3~5개 지역 인공 데이터로 다음을 검사한다.

- 기관 ±1 후 공급수준과 미관측 상태
- A→B 이전의 총량 보존
- 기관 삭제 후 인력 불일치 경고
- 상대부족도·부족자원·시급성 순위 변화
- 목표 초과배치 경고
- 전략 간 기준선 동일성
- 저장 후 동일 결과 재현

현재 자동배치 MVP의 테스트는 [test_engine.py](../04_분석코드/simulation/test_engine.py)에 있다.

- 설정·코드·데이터 버전으로 재실행 가능

프로그램은 실제 이용·서비스 질·건강·대기·돌봄부담·기관 진입 가능성·운영 지속가능성·정책 인과효과를 직접 추정하지 않는다. 강점은 최적 지역을 단정하는 것이 아니라 부족의 원인과 정책목표별 트레이드오프를 투명하게 비교하는 데 있다.

## 16. 현장 활용 확장 기능

다음 기능은 현장 공무원과 사회복지사가 분석 결과를 이해하고 후속 검토에 활용할 수 있도록 기존 진단·시뮬레이션 결과를 재구성하는 확장 범위다. 현재 보유한 공개자료와 7단계 시뮬레이션 산출물을 우선 사용하며, 실시간 기관 운영상태·대기자·개인정보가 필요한 기능은 포함하지 않는다.

| 기능 | 목적 | 현재 활용 가능한 자료 | 구현 상태 |
| --- | --- | --- | --- |
| 지역별 한 장 진단서 | 지역의 수요·취약성·공급·부족·시급성 근거를 한 화면과 한 페이지로 요약 | `region_summary`, `baseline`, `targets`, `warnings` | 설계 확정, 화면·출력 구현 예정 |

### 16.1 지역별 한 장 진단서

지역코드를 기준으로 다음 정보를 한 화면과 A4 1페이지에 배치한다.

1. 지역명, 분석범위, 자료 기준일
2. 총인구, 65세·85세 이상 인구 비율, 고령 1인세대 부담
3. 장기요양 인정수요, 인정자 비율, 수요 증가율
4. 서비스별 기관·서비스 제공인력·정원 현재량
5. 수요 1,000명당 공급수준, 목표량, 연속형 격차, 정수형 필요량
6. 목표충족률, 상대 자원부족도, 지역 내부 부족자원 순위
7. 지역취약성·수요압력·공급부족·공급공백 구성점수
8. 지원 시급성 점수와 순위, 상위 순위에 포함된 이유
9. 외부공급 반영 전후 격차와 완충효과
10. 데이터 경고, 해석 한계와 현장확인 항목

진단서의 우선순위는 자원 배분 확정순위가 아니라 현장확인 시작순서로 표시한다. 종합점수만 제시하지 않고 구성지표와 가장 부족한 서비스·자원을 병렬 표시한다.

권장 출력 열은 다음과 같다.

```text
region_code, sido_name, sigungu_name
data_reference_dates, demand_value, demand_growth
aging_rate, age_85_rate, elderly_single_household_burden
service, resource_type, current_resource, current_supply_level
target_supply_level, continuous_gap, integer_need
relative_shortage_score, resource_state, shortage_rank_within_region
vulnerability_score, demand_pressure_score, supply_shortage_score
service_void_score, urgency_score, urgency_rank
effective_continuous_gap, access_relief, data_warning
```

### 16.2 직종별 서비스 제공인력 표

화면에서는 `핵심인력`을 우선적으로 `서비스 제공인력`으로 표현하고, 분석에 포함한 직종을 함께 명시한다.

| 서비스 | 분석용 서비스 제공인력 | 함께 표시할 원자료 직종 |
| --- | --- | --- |
| 방문요양 | 요양보호사 | 사회복지사, 요양보호사 |
| 방문간호 | 간호사+간호조무사 | 간호사, 간호조무사 |
| 주야간보호 | 요양보호사 | 사회복지사, 간호사, 간호조무사, 요양보호사, 물리치료사, 작업치료사 |

직종별 수는 임의로 합산하지 않고 원자료 값을 그대로 제시한다. 시뮬레이션에 사용하는 서비스 제공인력 합계와 참고용 직종별 현황을 구분한다. 기관 단위 종사자 귀속이나 실제 근무시간을 알 수 없으므로 전일제 환산인력 또는 즉시 채용 가능한 인력으로 해석하지 않는다.

직종별 표에는 다음을 포함한다.

```text
service, provider_count, capacity
social_worker, nurse, nurse_assistant
physical_therapist, occupational_therapist, care_worker
simulation_workforce_definition, simulation_workforce_value
data_reference_date
```

### 16.3 실제 과거 추이와 미래 시나리오 연결

과거 관측값과 미래 계산값은 같은 그래프에서 구간과 선 유형을 달리 표시한다.

```text
과거 관측구간
- 장기요양 이용·급여: 2013~2024
- 고령인구: 2016~2025
- 장기요양 신청·인정수요: 2022~2025
- 기관·인력·정원 공급 스냅샷: 2023~2026

미래 시나리오 구간
- 사용자가 선택한 전망기간
- 수요 변화율
- 기존 공급 변화율
- 시작시점 일회성 자원변경
- 연도별 반복 순증감
```

미래값은 다음 규칙으로 계산한다.

```text
D_i(t) = D_i(0) × (1 + g_d)^t
S_baseline,isr(t) = S_isr(0) × (1 + g_s)^t
S_scenario,isr(t) = max(0, S_baseline,isr(t) + ΔS_initial,isr + t×ΔS_annual,isr)
M_isr(t) = T_sr × D_i(t) / 1,000
C_isr(t) = max(0, M_isr(t) - S_scenario,isr(t))
```

`g_d`와 `g_s`는 관측자료에서 계산한 참고값 또는 사용자 입력값이다. 관측 추세 적용 버튼을 제공하되, 전망은 통계적·인과적 예측이 아니라 입력조건이 지속된다고 가정한 결정적 시나리오라고 표시한다.

과거와 미래를 연결한 결과에는 다음을 제시한다.

- 과거 수요·공급 변화율
- 기준선과 자원변경 시나리오
- 연도별 공급격차와 상대 자원부족도
- 기간 누적 격차
- 최초 목표충족 연도
- 목표충족 후 재미달 여부
- 사용한 관측기간과 기준일

### 16.4 개선·악화지역 동시 표시

모든 수동변경·이전·자동배치·접근성 시나리오는 평균 또는 총량 개선만 보고하지 않고 지역별 방향을 함께 분류한다.

| 분류 | 판정 예시 |
| --- | --- |
| 직접 개선 | 자원을 변경한 지역의 공급격차 또는 상대부족도가 감소 |
| 간접 개선 | 접근권역 내 다른 지역의 유효공급격차가 감소 |
| 직접 악화 | 자원을 감축·이전한 원지역의 공급격차 또는 상대부족도가 증가 |
| 간접 악화 | 외부공급 감소로 접근권역 내 다른 지역의 유효공급격차가 증가 |
| 전환 개선 | 목표미달에서 목표충족으로 전환 |
| 전환 악화 | 목표충족에서 목표미달로 전환 |
| 변화 없음 | 비교 허용오차 안에서 주요 지표 변화 없음 |

필수 결과지표는 다음과 같다.

```text
improved_region_count, worsened_region_count, unchanged_region_count
direct_improved_count, indirect_improved_count
direct_worsened_count, indirect_worsened_count
deficit_to_attainment_count, attainment_to_deficit_count
access_void_created_count, access_void_resolved_count
origin_region_loss, beneficiary_region_gain
total_gap_change, effective_total_gap_change
urgency_rank_change, top_shortage_resource_change
```

악화지역이 1곳 이상이면 결과 상단에 경고를 표시한다. 총량고정 이전에서는 원지역 손실과 수혜지역 이득을 별도 표로 제공한다.

### 16.5 자동 배치전략 비교

동일한 서비스·자원유형·총량·목표기준·지역당 상한을 고정한 뒤 다음 전략을 비교한다.

| 자원 | 비교전략 |
| --- | --- |
| 기관 | 수요비례, 공급부족량 우선, 기관 미관측 우선, 지역취약성 우선, 지원 시급성 우선 |
| 서비스 제공인력 | 수요비례, 공급부족량 우선, 지역취약성 우선, 지원 시급성 우선 |
| 정원 | 수요비례, 공급부족량 우선, 지역취약성 우선, 지원 시급성 우선 |

전략 비교화면의 공통 입력은 다음과 같다.

```text
region_scope, service, resource_type
total_budget, target_rule, target_value
max_per_region, minimum_allocation_unit
strategy, vulnerability_weights, urgency_weights
use_local_gap_or_effective_gap
```

전략별 출력은 배치지역·배치량·미배치량, 총 공급격차 변화, 목표 미달지역 변화, 기관 미관측 변화, 개선·악화지역 수, 하위지역 개선, Gini·IQR 변화, 상위 시급지역 포착률을 포함한다. 전략 이름만으로 우열을 정하지 않고 효율성·최소보장·형평성·안전성의 트레이드오프를 함께 보여준다.

### 16.6 데이터 기준일·품질 경고

모든 화면과 보고서는 사용한 자료의 기준일을 공통 영역에 표시한다. 서로 다른 기준시점의 자료를 결합한 경우 가장 오래된 기준일과 항목별 기준일을 모두 제공한다.

경고 유형은 다음과 같다.

| 코드 | 의미 | 화면 처리 |
| --- | --- | --- |
| `SUPPLY_ROW_MISSING` | 공급 원자료 행 미관측 | 0 처리 여부와 현장확인 필요 표시 |
| `PROVIDER_MISSING` | 기관 수 0 또는 미관측 | 공급기반 미확인 배지 |
| `DEMAND_SUPPRESSED` | 비공개 셀 포함 | 공개값·하한·상한 구분 |
| `REFERENCE_DATE_MISMATCH` | 수요·공급·인구 기준일 차이 | 기준일 불일치 경고 |
| `OCCUPANCY_UNINTERPRETABLE` | 현원·정원 결측으로 가동률 해석 불가 | 가동률 미표시 |
| `ACCESS_ASSUMPTION` | 실제 이동시간이 아닌 탐색 가중치 | 접근성 가정 배지 |
| `SCENARIO_ONLY` | 관측결과가 아닌 계산 시나리오 | 확정값 아님 표시 |

`audit.csv`, `warnings.csv`, `run_metadata.json`을 공통 데이터 품질 패널의 입력으로 사용한다. 경고는 결과에서 제거하지 않고 해당 지역·지표·보고서에 함께 전달한다.

### 16.8 외부공급 기여지역 상세보기

지역 `i`의 접근 가능 외부공급을 구성하는 원지역 `j`를 서비스·자원별로 추적한다.

```text
origin_region_code, destination_region_code
scope, service, resource_type
source_current_resource, source_target_resource
source_available_resource, access_weight
weighted_external_resource
```

상세화면에는 다음을 표시한다.

1. 선택 지역이 공급을 제공받는 외부지역 목록
2. 외부지역별 현재량·목표량·계산상 잉여량
3. 적용한 접근범위와 서비스별 가중치
4. 외부지역별 가중 반영 공급량
5. 외부공급 반영 전후 격차와 상대부족도
6. 자원변경 전후 기여량 변화
7. 해당 연결이 사라질 때 영향을 받는 지역

주분석은 외부지역이 자기 목표를 충족하고 남은 잉여량만 공유하는 모드다. 현재 보유한 접근링크가 같은 도 기반이면 이를 실제 인접관계나 이동시간으로 표현하지 않는다. 향후 인접행렬 또는 이동시간 자료가 확보되면 같은 화면 구조에서 접근범위를 교체한다.

### 16.9 화면 흐름

```text
한눈에 보기
→ 지역 선택
→ 지역별 한 장 진단서
→ 직종별 서비스 제공인력·과거 추이 확인
→ 수동 자원변경 또는 자동 배치전략 선택
→ 미래 시나리오와 접근성 간접영향 재계산
→ 개선·악화지역 동시 확인
→ 데이터 품질 경고 검토
→ PDF·CSV 보고서 출력
```

사용자는 종합점수에서 바로 배치결정을 내리지 않고 진단 근거, 원자료 직종, 과거 추이, 외부공급 기여, 악화지역과 데이터 경고를 순서대로 확인할 수 있어야 한다.

### 16.10 개발 우선순위와 완료 기준

| 순서 | 기능 | 완료 기준 |
| ---: | --- | --- |
| 1 | 지역별 한 장 진단서 | 76개 군 모두 동일 필드로 조회되고 기준일·경고가 표시됨 |
| 2 | 직종별 서비스 제공인력 표 | 분석용 합계와 원자료 직종별 수가 분리 표시됨 |
| 3 | 과거 추이와 미래 시나리오 연결 | 관측구간과 시나리오 구간이 시각적으로 구분되고 설정이 저장됨 |
| 4 | 개선·악화지역 동시 표시 | 모든 변경모드에서 개선·악화·전환 지역이 재계산됨 |
| 5 | 자동 배치전략 비교 | 동일 조건으로 모든 적용가능 전략의 배치와 성과가 비교됨 |
| 6 | 데이터 기준일·품질 경고 | 원자료 경고가 화면·PDF·CSV에 동일하게 전달됨 |
| 7 | 외부공급 기여지역 상세보기 | 기여량 합계가 유효 외부공급과 일치하고 전후 추적이 가능함 |
| 8 | PDF·CSV 보고서 출력 | 화면 핵심값과 보고서 값이 일치하며 메타데이터로 재실행 가능함 |

이 확장기능은 공개자료 기반의 지역 자원계획과 현장확인 지원을 목적으로 한다. 기관별 실시간 신규접수 가능 여부, 대기자 수, 실제 이동시간, 개인별 서비스 연계, 설치·운영비와 실제 채용 가능성은 별도 자료 또는 현장입력이 확보되기 전까지 제공하지 않는다.

## 17. 추가 자료수집 없이 적용하는 현장 의사결정 지원

추가적인 기관 운영자료·대기자·이동시간·채용가능성 자료를 확보하기 어려운 조건에서는 분석모형을 확대하기보다, 현재 계산결과를 공무원과 사회복지사의 검토업무로 번역하는 기능을 우선한다. 프로그램은 자원배치 결정을 대신하지 않고 `지역 선별 → 대안 비교 → 위험 확인 → 담당자 검토기록`을 일관된 형식으로 지원한다.

### 17.1 지역별 자동 결론 요약

지역을 선택하면 다음 내용을 3문장 이내로 자동 요약한다.

1. 상대적으로 가장 부족한 서비스와 자원
2. 지역 내부 기관 미관측 여부와 외부공급 완충 가능성
3. 76개 군 중 현장검토 순위와 순위의 해석

요약은 원자료와 계산결과만 사용하며 `지원해야 한다`가 아니라 `우선 검토해야 한다`로 표현한다. 자동요약의 입력 필드는 `top_shortage_service`, `top_shortage_resource_type`, `provider_missing`, `total_access_relief`, `urgency_rank`다.

### 17.2 결과를 실무 행동으로 번역

| 계산 신호 | 화면의 실무 검토문구 |
| --- | --- |
| 기관 0 또는 미관측 | 신규 설치 가능성 또는 외부지역 연계 가능성 우선 검토 |
| 기관 존재·서비스 제공인력 부족 | 신규 기관보다 기존 기관의 인력확보 가능성 우선 검토 |
| 주야간보호 정원 부족 | 기존 기관의 정원 확대와 제공인력 동반 확보 여부 검토 |
| 외부공급으로 부족 완화 | 광역·인접지역 공동이용과 실제 이동·수용 가능성 검토 |
| 외부공급 반영 후에도 미달 | 지역 내부 공급기반 검토 우선 |
| 감축 후 목표미달 전환 | 감축안 재검토 경고 |
| 미래 시나리오에서 목표미달 | 중기 자원확보계획 검토 |

이 문구는 행정처분·설치명령·예산확정이 아니라 후속 확인항목이다.

### 17.3 3단계 탐색 목표

단일 중앙값 목표에 대한 의존성을 줄이기 위해 동일한 76개 군 공급수준 분포에서 세 목표를 병렬 계산한다.

```text
최소기반 = 서비스×자원별 공급수준 제1사분위수
기본목표 = 서비스×자원별 공급수준 중앙값
상향목표 = 서비스×자원별 공급수준 제3사분위수
```

각 목표별 현재 충족·미달, 연속형 격차와 상대부족도를 표시한다. 세 값은 법정 기준이나 정부의 공식 적정량이 아니라 지역 간 비교를 위한 탐색 기준이다. 기관 미관측 상태는 목표 충족 여부와 별개로 선행 경고한다.

### 17.4 현실적인 사전 시나리오

자유 입력과 함께 다음 사전 시나리오를 제공한다.

- 현재 상태 유지
- 기관 1곳 신설
- 기관 1곳 폐업
- 서비스 제공인력 3명 확충
- 서비스 제공인력 3명 유출
- 주야간보호 정원 10명 확충
- 공급 정체와 수요 증가
- 최근 관측 공급추세 유지

사전 시나리오를 선택하면 동일한 지역·서비스·자원 조건을 수동 변경과 미래 화면에 전달한다. 사용자는 이후 변경량과 전망 가정을 수정할 수 있다.

### 17.5 기관·인력·정원의 연계경고

- 기관이 없는 지역에 서비스 제공인력만 추가하지 않는다.
- 주야간보호기관이 없는 지역에 정원만 확충하지 않는다.
- 기관 추가 시 제공인력 확보가 별도 검토사항임을 표시한다.
- 기관 폐업 시 인력·정원의 자동 감소량을 임의 추정하지 않고 불일치 가능성을 경고한다.
- 인력 부족이 유지되면 기관 추가가 실제 제공역량 확대로 이어지지 않을 수 있음을 표시한다.

현재 공개 집계자료로 기관별 인력 귀속을 알 수 없으므로 기관과 인력의 자동 연동량은 계산하지 않는다.

### 17.6 시나리오 의사결정 비교표

동일 지역의 복수 검토안을 다음 열로 비교한다.

```text
scenario_name, service, resource_type
before_resource, delta_resource, after_resource
gap_after, gap_change, relative_shortage_after
target_state_after, structural_warning
improved_region_count, worsened_region_count
complete_access_void_change, final_year_gap
```

표에는 개선뿐 아니라 감축 원지역 손실, 간접 악화, 목표충족에서 미달로 전환, 완전 접근공백 발생을 함께 표시한다. `추천안`과 `최적안` 대신 `검토안`과 `조건부 배치안`을 사용한다.

### 17.7 감축·폐업 위험 알림

다음 조건을 결과 상단의 경고로 제공한다.

- 감축 즉시 목표미달 전환
- 기관 수가 0으로 전환
- 완전 접근공백 신규 발생
- 접근권역 내 간접 악화
- 지원 시급지역 상위 10개 신규 진입
- 전망기간 안 공급격차 급증
- 같은 도에서 계산상 대체공급을 확인할 수 없음

위험 알림은 사건 발생확률이 아니라 입력한 감축조건에서 발생한 결정적 계산결과다.

### 17.8 결과 해석 신뢰 표시

정밀한 통계적 신뢰도가 아니라 현재 자료의 적용상태를 다음처럼 표시한다.

| 표시 | 조건 |
| --- | --- |
| 비교 가능 | 필수 기준선 자료가 있고 주요 민감도에서 방향이 유지됨 |
| 민감도 주의 | 목표·가중치·수요조건에 따라 상위지역 또는 부족자원이 달라짐 |
| 제한적 해석 | 기관 미관측·비공개 셀·기준일 불일치·접근성 가정의 영향이 큼 |

등급 옆에는 판정 사유를 반드시 함께 제공한다. 등급은 원자료의 정확성을 인증하지 않는다.

### 17.9 회의 전 검토 체크리스트

지역 진단서와 보고서에 다음 체크리스트를 제공한다.

- 현재 자원값과 자료 기준일을 확인했는가?
- 기관과 서비스 제공인력을 구분했는가?
- 외부공급이 실제 이동 가능성이 아닌 계산 가정임을 확인했는가?
- 목표기준 변화에 따른 결과 차이를 확인했는가?
- 개선지역과 악화지역을 모두 확인했는가?
- 계산 부족량을 공식 필요량으로 표현하지 않았는가?
- 최종 결정 전 담당부서 검토 필요성을 기록했는가?

체크는 분석 완료나 현장검증을 증명하지 않으며 회의·보고 과정의 누락을 줄이는 용도다.

### 17.10 구현구조와 우선순위

대시보드 화면과 시뮬레이션 규칙을 분리한다.

```text
web-dashboard/
├── app/                         # 화면·상태·스타일
├── 시뮬레이션_구성_코드/
│   ├── field-support.ts         # 자동요약·검토문구·목표·사전안·신뢰표시
│   └── README.md
├── public/data/                 # 기준선·접근성·배치·품질 산출물
└── tests/                       # 화면 문구·데이터·불변조건 검사
```

구현 우선순위는 `자동 결론 → 실무 검토문구 → 3단계 목표 → 사전 시나리오 → 연계·감축경고 → 의사결정표 → 신뢰 표시 → 체크리스트·출력`이다. 추가 자료 없이 제공 가능한 기능과 자료 확보 전 제공할 수 없는 기능을 화면에서 구분한다.

현 단계에서 가능한 활용범위는 지역 간 1차 선별, 부서회의, 조건부 자원조정안 비교, 현장확인 대상 선정이다. 실제 예산확정, 기관 설치·폐업 결정, 인력 채용계획의 단독 근거로 사용하지 않는다.
