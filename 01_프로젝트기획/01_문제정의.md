# 도 소속 농촌 군의 장기요양 자원부족 진단과 자원변경·재배치 문제 정의

> **문서 상태: 계획 단계 기록.** 실제 수행 방법과 해석은 [현재 분석방법론](../02_분석보고서/01_분석방법론.md)을 우선합니다.

> 이 문서는 도 소속 군의 재가서비스 수요 대비 공급수준과 추가 필요량을 왜 진단해야 하며, 제한된 추가 자원의 배치전략별 효과를 왜 비교해야 하는지 정의한다.

## 1. 제출자와 주제

- 제출자: 이소이
- 분석 주제: 도 소속 76개 군을 대상으로 방문요양·방문간호·주야간보호의 공통 잠재수요 대비 공급수준과 목표기준 대비 기관·핵심인력·정원의 연속형 공급격차와 정수형 추가 필요량을 진단한다. 이후 동일한 서비스·자원유형과 총량을 고정하고 해당 자원유형에 적용 가능한 위치전략을 적용했을 때 공급부족과 지역격차가 어떻게 변하는지 비교한다. 부족구성 맞춤형 배치는 자원유형을 함께 선택하는 보조 종합 시나리오로 구분한다.
- 주분석 대상: 행정구역명이 군이고 시도명이 도로 끝나는 76개 군의 전수 집계자료
- 비교기준: 현재 공급수준의 외부 비교는 전국 시군구 분포를 참고하고, 공급부족·추가 필요량 산출과 기본 시뮬레이션 목표는 도 소속 76개 군의 서비스·자원유형별 분포를 사용한다. 82개 전체 군은 지역범위 민감도 분석에 사용한다.

본 연구에서 `농촌 군`은 국가의 공식 농촌 분류가 아니라 위 76개 군을 뜻하는 조작적 정의다. 광역시 소속 6개 군은 행정·재정·서비스 환경 차이를 줄이기 위해 주분석에서 제외하며, 82개 군을 포함하는 분석은 민감도 분석으로 수행한다. 분석 전부터 모든 대상 군을 `공급 취약지역`으로 전제하지 않는다.

서비스 범위는 방문요양·방문간호·주야간보호로 고정한다. 방문목욕·단기보호 등 다른 재가급여는 본 연구의 진단·시뮬레이션 범위에서 제외한다.

장기요양 인정자 수는 세 서비스를 비교하기 위한 공통 잠재수요 분모이며, 모든 인정자가 세 서비스를 동일하게 필요로 한다는 뜻은 아니다. 서비스별 실제 이용비중과 인정자 하한·중앙값·상한, 65세·85세 이상 인구는 수요정의 민감도 분석에 사용한다. 목표기준은 공식 부족·적정 기준이 아니라 전략 비교를 위한 탐색적 시뮬레이션 기준이다.

Q5-B는 같은 자원을 어디에 배치할지 비교하고, Q5-C는 자원유형별 총량 제약 아래 무엇을 우선 검토할지 제시한다. 두 결과는 조건이 달라 같은 순위표에서 직접 비교하지 않는다.

총 추가 필요량은 동일한 서비스×자원유형 시나리오 안에서만 지역별 정수형 추가 필요량을 합산한다. 방문요양기관·방문요양 요양보호사·방문간호기관·방문간호 간호인력·주야간보호기관·주야간보호 요양보호사·주야간보호 정원은 각각 별도 지표다. 기관 수·인력 수·정원 수를 합친 종합 총량은 산출하지 않으며, 전략별 공급부족 개선량과 자원 1단위당 부족량 감소도 같은 서비스×자원유형 안에서만 계산한다.

## 3. 고객 정의

### 최종 고객

> 도 소속 군에서 재가 장기요양서비스의 수요 대비 공급수준과 추가 필요량을 파악하고, 동일한 서비스·자원유형과 총량을 고정한 상태에서 우선 현장검토할 지역과 배치전략을 비교하는 군청 노인복지·통합돌봄 담당자

- 사용자: 군청 실무 담당자
- 의사결정자: 과장·보건소장·복지부서 책임자
- 구매자: 군청·도청·지역연구원
- 최종 수혜자: 장기요양 인정 노인과 가족

장기요양 인정 노인과 가족은 분석서비스의 직접 사용자가 아니라 담당자의 사업·연계 결정으로 영향을 받는 최종 수혜자다.

### 분석 결과를 사용할 사람

군청 담당자는 시뮬레이션 결과를 통해 신규 기관 설치, 핵심인력 지원, 주야간보호 정원 확충, 기존 기관 연계 중 무엇을 먼저 현장 검토할지 정한다. 결과는 사업계획서·지역사회보장계획·공모사업·예산설명자료의 근거로 활용하되 실제 설치 확정안으로 사용하지 않는다.

### 고객 정의 한 문장

> 농촌 군의 노인복지·통합돌봄 담당자는 세 서비스의 수요 대비 공급수준과 추가 필요량을 확인하고, 동일 자원의 배치 위치별 공급부족 감소 효과를 비교할 통합 근거가 필요하다.

## 4. 고객 문제 정의

### 핵심 진단 문제

> 담당자는 기관 수는 확인할 수 있지만, 서비스별 수요 대비 현재 공급수준이 어느 정도이고 설정한 목표기준까지 기관·핵심인력·정원이 각각 얼마나 더 필요한지 파악하기 어렵다.

### 보조 진단 문제

> 공급이 낮은 지역에서 부족이 기관·핵심인력·주야간보호 정원 중 어디에서 나타나는지와 어떤 요소가 공급을 제약할 가능성이 있는지 구분하기 어렵다.

### 배치 문제

> 담당자는 추가 자원의 총량이 제한된 상황에서 동일한 서비스·자원유형과 총량을 어느 지역에 우선 배치해야 총 추가 필요량·목표 미달지역 수와 지역격차를 더 많이 줄일 수 있는지 비교하기 어렵다.

### 현재 관찰한 상태

- 수요 대비 현재 공급수준과 목표기준까지의 추가 필요량을 지역·서비스·자원유형별로 바로 확인하기 어렵다.
- 공급부족이 기관·인력·정원 중 어디에서 나타나는지 보조적으로 구분하기 어렵다.
- 인구·인정수요·기관·인력·이용자료의 시점과 지역단위가 다르다.
- 보건소·재택의료센터와 인접지역 기관을 대안으로 함께 볼 기준이 없다.
- 서비스별 자원 단위가 달라 기관 1개·인력 1명·정원 1명을 같은 자원으로 비교할 수 없다.
- 추가 자원을 어디에 배치할지 비교하는 재현 가능한 규칙과 성과지표가 없다.

### 기대하는 상태

- 서비스별 공급구조 차이를 반영한 공통 지표체계로 수요 대비 공급수준을 계산한다.
- 목표기준 대비 자원유형별 추가 필요량을 산출한다.
- 기관·인력·정원·이용자료로 부족의 구성과 공급제약 가능성을 보조 진단한다.
- 방문요양·방문간호·주야간보호를 각각 분석한다.
- 동일한 서비스·자원유형과 총량을 고정한 상태에서 기본 배치 위치전략의 효과를 비교한다.
- 지역별 개선량과 전체 격차 변화를 함께 제시한다.
- 결과를 설치 확정안이 아니라 현장조사와 사업검토 우선순위로 사용한다.

### 고객이 겪는 불편과 영향

근거가 분산돼 담당자가 반복적으로 자료를 정리하고, 기관이 적다는 이유만으로 신규 설치를 검토할 수 있다. 실제 원인이 인력·이용연계 또는 접근성이라면 제한된 예산을 잘못 배치할 위험이 있다.

### 문제 정의 한 문장

> 도 소속 군 담당자는 세 재가서비스의 공통 잠재수요 대비 현재 공급수준과 목표기준까지의 연속형 공급격차·정수형 추가 필요량을 알기 어렵고, 동일한 서비스·자원유형과 총량을 어느 지역에 배치할 때 공급격차와 지역격차를 더 줄이는지 비교할 통합자료와 재현 가능한 규칙이 부족하다.

| 공급기반 미관측 | 기관 수 0 |
| 상대적 기관 저공급 후보 | 서비스별 기관 공급률이 도 소속 군의 제1사분위수 미만 |
| 상대적 인력 저수준 후보 | 기관은 존재하지만 핵심인력 공급률이 제1사분위수 미만 |
| 상대적 정원 저수준 후보 | 주야간보호 정원 공급률이 제1사분위수 미만 |
| 구조적 인력·정원 공급제약 후보 | 기관이 존재하고 기관 공급률 대비 핵심인력 또는 정원 공급률의 서비스별 표준화 잔차가 하위 20% |
| 우선 확인 공급제약 | 제1사분위수 저수준 조건과 잔차 하위 20% 조건을 모두 충족 |
| 이용·연계 확인 필요 | 같은 2024년 비교에서 공급은 중앙값 이상이나 이용지표가 제1사분위수 미만 |
| 복합 부족 구성 | 기관이 존재하는 지역에서 서로 다른 부족 요소의 조건을 두 개 이상 충족 |

제1사분위수는 공식 부족기준이 아니라 현재 분포에서 현장확인 순서를 정하기 위한 탐색적 기준이다. 공급기반 미관측은 최우선 배타적 유형으로 분류하며, 기관 0으로 인해 인력·정원도 0인 경우 별도의 복합 부족 구성으로 중복 계산하지 않는다.

### 핵심 분석 질문

1. **Q1 현재 공급과 상대 자원부족:** 내부 공급과 사용자 접근범위의 유효공급은 어떻게 다르며 상대부족도와 부족자원 순위는 어떻게 달라지는가?
2. **Q2 공급기반과 제공역량:** 기관 수준이 유사해도 인력·정원이 다르며 기관 수로 설명되지 않는 공급제약 후보는 어디인가?
3. **Q3 지역특성과 자원부족:** 고령화·돌봄취약성·수요압력은 내부·접근성 반영 부족과 완전 접근공백에 어떤 관련성을 보이는가?
4. **Q4 지원 시급지역:** 취약성·수요압력·접근성 반영 부족·접근성 불리·완전 접근공백을 고려할 때 어디가 시급하며 순위는 안정적인가?
5. **Q5-A 수동 자원변경:** 추가·감축·이전 시 직접 영향지역과 접근권역 간접 영향지역은 어떻게 변하는가?
6. **Q5-B 자동 배치전략:** 내부 또는 접근성 반영 부족을 기준으로 동일 총량을 배치할 때 전략별 직접·간접 효과와 격차는 어떻게 다른가?
7. **Q5-C 자원유형 선택:** 부족 구성과 자원별 총량 제약 아래 어떤 자원을 우선 검토하는가?

### 확장된 고객문제와 기대상태

담당자는 현재 어떤 자원이 상대적으로 부족한지뿐 아니라 기관 폐업·인력유출·정원축소, 신규 지원과 지역 간 이전이 원지역·수혜지역·접근권역에 미치는 손익을 함께 확인해야 한다. 기대상태는 수동 시나리오 작성·저장, 총량고정 재배치, 자동전략 비교, 악화지역 경고와 현장검증 항목을 동일 기준선에서 재현하는 것이다.

행정구역 밖 공급은 `군 내부·인접 시군·같은 도·사용자 지정 집합` 중 선택한 범위로 계산하며 이동시간 기준은 후속 확장이다. 외부공급을 고려해도 실제 이용가능성을 확정하지 않는다.

## 6. 사실·해석·추가 확인

### 데이터와 선행연구에서 확인된 사실

- 수요 정의에 따라 공급 적정성 결과가 달라질 수 있다.
- 선행연구에서 방문요양·방문간호는 농촌보다 도시지역에 집중되는 경향이 확인됐다.
- 방문형 서비스는 정원 가동률보다 기관·인력·실제 이용을 봐야 한다.
- 인접지역의 공급도 이용과 대기에 관련될 수 있다.

### 아직 가설인 해석

- 고령화율과 고령 1인세대 부담지표가 높은 군일수록 일부 서비스 공급수준이 낮을 수 있다.
- 기관 수가 비슷해도 인력·정원 수준에 따른 부족의 구성과 공급제약 가능성은 다를 수 있다.
- 동일한 서비스·자원유형과 총량의 배치 위치전략은 총 추가 필요량·목표 미달지역 수와 지역격차에서 서로 다른 계산상 결과를 보일 것이다.

### 현재 데이터만으로 알 수 없는 내용

- 개인별 필요서비스와 실제 미충족 인원
- 기관별 실근무 FTE·서비스 제공 가능시간
- 대기·거절·연계실패와 실제 이동시간
- 자원 추가가 건강·삶의 질에 미치는 인과효과

### 추가로 필요한 데이터

- 군청·공단의 대기·거절·연계·이용개시 기록
- 기관별 실근무 FTE·채용공석·운영시간
- 이용자와 기관 간 도로망 이동시간
- 사업별 비용·예산과 보완자원 실제 연계역량
