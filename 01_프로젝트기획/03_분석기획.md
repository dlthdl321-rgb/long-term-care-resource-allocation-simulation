# 재가서비스 자원부족 진단과 자원변경·재배치 시뮬레이션 분석 기획

> **문서 상태: 계획 단계 기록.** 계획과 실제 수행이 다를 경우 [현재 분석방법론](../02_분석보고서/01_분석방법론.md)을 기준으로 확인합니다.

> 이 문서는 서비스별 수요 대비 공급수준과 추가 필요량 진단, 배치전략별 효과 비교에 필요한 질문·변수·계산식·제약조건·성과지표를 설계한다. 부족의 구성과 공급제약 가능성은 보조 분석으로 다룬다.

- 분석 문제: 도 소속 군의 방문요양·방문간호·주야간보호 수요 대비 현재 공급수준과 목표기준 대비 추가 필요량을 자원유형별로 진단하고, 동일한 서비스·자원유형과 총량을 고정한 상태에서 배치 위치규칙을 적용하여 공급부족과 지역격차의 예상 변화를 비교한다. 기관·인력·정원·이용에 따른 부족의 구성은 결과 해석과 보조 시나리오 설계에 활용한다.
- 주분석 대상: 행정구역명이 군이고 시도명이 도로 끝나는 76개 군의 전수 집계자료
- 비교기준: 현재 공급수준의 외부 비교는 전국 시군구 분포를 참고하고, 추가 필요량 산출과 기본 시뮬레이션 목표는 도 소속 76개 군의 서비스·자원유형별 분포를 사용한다. 82개 전체 군은 지역범위 민감도 분석에 사용한다.
- 핵심 서비스: 방문요양·방문간호·주야간보호

`농촌 군`은 국가의 공식 농촌 분류가 아니라 위 76개 군을 뜻하는 조작적 정의다. 광역시 소속 6개 군을 포함한 82개 군 분석은 민감도 분석으로 구분한다.

## 3. 데이터 기본 개념 정리

### 3.1 정책 대상집단·분석 모집단과 분석자료

- 정책 대상집단: 도 소속 군에서 재가 장기요양서비스가 필요하거나 이용하는 노인과 가족
- 분석 모집단: 행정구역명이 군이고 시도명이 도로 끝나는 76개 군
- 분석 단위: 군×서비스 또는 군
- 자료 성격: 분석 모집단 76개 군의 전수 집계자료
- 일반화 한계: 지역 집계자료의 관계를 개인의 욕구나 미충족 원인으로 해석하지 않는다.

| --- | --- | --- |

### 3.4 수요·취약성·이용 변수의 역할

| 변수 | 분석상 역할 |
| --- | --- |
| 장기요양 인정자 | 공급수준 계산의 주 수요 분모 |
| 65세 이상 인구 | 잠재 수요와 지역 인구구조 |
| 85세 이상 인구 | 고위험 잠재 수요 보조지표 |
| 고령 1인세대 | 비공식 돌봄 취약성 보조지표 |
| 2024년 이용자·제공일수 | 실현된 이용의 보조지표 |

수요 정의에 따라 공급수준 결과가 달라질 수 있으므로 주분모는 장기요양 인정자로 고정하고, 나머지는 취약성 분석 또는 민감도 분석에 사용한다.

장기요양 인정자 수는 세 서비스를 비교하기 위한 공통 잠재수요 분모이며, 모든 인정자가 방문요양·방문간호·주야간보호를 동일하게 필요로 한다는 뜻은 아니다.

| 수요 시나리오 | 정의 | 역할 |
| --- | --- | --- |
| 주분석 | 지역별 장기요양 인정자 추정 중앙값 | 세 서비스의 공통 잠재수요 분모 |
| 인정자 불확실성 | 인정자 추정 하한·중앙값·상한 | 비공개 구간에 따른 민감도 |
| 서비스별 추정수요 | `지역 인정자 수 × 서비스별 이용 또는 필요 비율` | 확정값이 아닌 민감도 시나리오 |
| 인구 기반 | 65세 이상 또는 85세 이상 인구 | 잠재수요 정의 변화 보조 시나리오 |

서비스별 이용 또는 필요 비율이 충분히 검증되지 않은 경우 서비스별 추정수요는 정책 입력값의 범위로 실행하고 실제 필요자 수로 해석하지 않는다.

방문형 서비스에는 주야간보호의 정원 개념을 적용하지 않는다.

## 4. 지표 정의와 계산식

### 지표 0. 접근 가능 공급

접근범위 `a`는 군 내부, 인접 시·군, 같은 도, 사용자 지정 지역집합을 지원하며 이동시간 기준은 후속 확장이다.

```text
S_effective_isr(a) = S_local_isr + S_accessible_isr(a)
S_accessible_isr(a)
= Σ[j∈N_i(a), j≠i] w_ij(a,s) × S_available_jsr
```

주분석은 외부지역이 자기 목표를 충족하고 남은 잉여량 `E_jsr=max(0,S_local_jsr-M_jsr)`만 공유하는 `잉여공급 공유 모드`다. 외부 현재자원 전체에 가중치를 적용하는 `단순 접근 모드`는 민감도 분석이다.

| 범위 | 방문요양 | 방문간호 | 주야간보호 |
| --- | ---: | ---: | ---: |
| 내부 | 1.00 | 1.00 | 1.00 |
| 인접지역 | 0.50 | 0.50 | 0.30 |
| 같은 도 비인접 | 0.15 | 0.15 | 0.05 |

가중치는 공식 접근성 기준이 아닌 사용자 입력값이다. 내부/유효 공급수준, 내부/접근성 반영 격차, 내부/접근성 반영 상대부족도와 `접근성으로 완화된 공급격차`를 각각 저장한다.

### 지표 1. 지역 취약성

```text
고령화율(%) = 65세 이상 인구 ÷ 총인구 × 100
85세 이상 인구 비율(%) = 85세 이상 인구 ÷ 총인구 × 100
고령 1인세대 부담지표 = 65세 이상 1인세대 수 ÷ 65세 이상 인구 × 100
장기요양 인정자 비율(%) = 인정자 추정 중앙값 ÷ 65세 이상 인구 × 100
인정자 증가율(%) = (당해 인정자−기준연도 인정자) ÷ 기준연도 인정자 × 100
```

고령 1인세대 부담지표는 세대 수를 인구 수로 나눈 **대리지표**이며 개인 단위의 실제 독거노인 비율이나 구성비가 아니다. 따라서 `%` 대신 `65세 이상 인구 100명당 고령 1인세대 수`로 표시한다. Q3의 관련성 분석에서는 각 취약성 지표를 독립적으로 사용하며 통계검정 결과를 하나의 합성점수로 축약하지 않는다.

### 지표 2. 서비스별 수요 대비 공급수준과 추가 필요량

```text
인정자 1,000명당 기관 수 = 전처리된 공급자료의 서비스별 기관 수 ÷ 인정자 수 × 1,000
인정자 1,000명당 핵심인력 = 서비스별 핵심인력 수 ÷ 인정자 수 × 1,000
인정자 1,000명당 정원 = 적용 서비스 정원 ÷ 인정자 수 × 1,000
인정자 1,000명당 연간 이용자 = 해당 연도 서비스 이용자 수 ÷ 같은 연도 인정자 수 × 1,000
인정자 1,000명당 연간 제공일수 = 해당 연도 서비스 제공일수 ÷ 같은 연도 인정자 수 × 1,000
```

지역 `i`, 서비스 `s`, 자원유형 `r`에 대해 다음과 같이 정의한다.

```text
공급수준 = 현재 공급량 ÷ 서비스 수요 × 1,000
목표 공급량_isr = 목표 공급수준_sr × 서비스 수요_is ÷ 1,000
연속형 공급격차_isr = max(0, 목표 공급량_isr - 현재 공급량_isr)
정수형 추가 필요량_isr = max(0, ceil(목표 공급량_isr) - 현재 공급량_isr)

R_isr = S_isr / D_is × 1,000
C_isr = max(0, T_sr × D_is / 1,000 - S_isr)
G_isr = max(0, ceil(T_sr × D_is / 1,000) - S_isr)
```

- `D_is`: 지역 `i`의 서비스 `s` 수요
- `S_isr`: 지역 `i`·서비스 `s`·자원 `r`의 현재 공급량
- `T_sr`: 서비스 `s`·자원 `r`의 목표 공급수준
- `R_isr`: 수요 1,000명당 현재 공급수준
- `C_isr`: 목표기준 대비 연속형 공급격차
- `G_isr`: 목표기준 대비 정수형 추가 필요량

주분석에서는 세 서비스 모두 동일한 장기요양 인정자 기반 공통 잠재수요를 사용하므로 `D_is = D_i`로 둔다. 서비스별 이용률 또는 필요 비율을 적용하는 민감도 시나리오에서만 `D_is`가 서비스별로 달라진다.

연속형 공급격차는 현재 공급이 탐색 목표에서 얼마나 떨어져 있는지 나타내는 분석지표이며 분포와 민감도 결과를 설명하는 보조지표로 사용할 수 있다. 정수형 추가 필요량은 기관·인력·정원을 실제 정수 단위로 배치하기 위한 시뮬레이션 입력값이다. 기관·인력·정원 배치에는 정수형 추가 필요량을 사용한다. `ceil` 적용은 공식 필요량 추정이 아니라 탐색 목표를 정수 자원으로 변환하기 위한 계산규칙이다. 진단표에는 목표 공급량, 연속형 공급격차와 정수형 추가 필요량을 함께 저장한다.

기관·핵심인력·주야간보호 정원은 합산하지 않고 자원유형별로 별도 계산한다. 총 추가 필요량은 동일한 서비스×자원유형 시나리오 안에서만 지역별 정수형 추가 필요량을 합산한다. 방문요양기관·방문요양 요양보호사·방문간호기관·방문간호 간호인력·주야간보호기관·주야간보호 요양보호사·주야간보호 정원 총 추가 필요량은 각각 별도 지표이며, 기관 수·인력 수·정원 수를 더한 종합 총량은 산출하지 않는다.

- 방문요양: 기관·요양보호사·이용자·제공일수
- 방문간호: 기관·간호인력·이용자·제공일수
- 주야간보호: 기관·정원·신고 요양보호사·이용자·제공일수

주야간보호 핵심인력은 `신고 요양보호사 수`로 고정한다. 간호인력·사회복지사 등은 직종별 보조지표로 분리하며 핵심인력에 합산하지 않는다. 서비스별 기관 수는 시설현황 원자료의 기관식별자를 기준으로 기관유형코드별 중복을 제거하고, 정원자료와 인력자료에 나타난 기관 집합의 합집합을 시군구×기관유형으로 집계하였다. 이후 방문요양은 `B01+C01`, 방문간호는 `B05+C05`, 주야간보호는 `B03+C03`으로 합산한다. Python 전수 검산 결과 2026년 자료에서 각 서비스의 B/C 코드에 동시에 포함된 기관은 모두 0건이므로 서비스 내 중복합산은 발생하지 않았다. 다른 기준시점 자료를 사용할 때는 같은 중복검사를 다시 수행한다.

서비스별 필요자가 공개되지 않으므로 전체 인정자를 공통 잠재수요 분모로 쓰되, 모든 인정자가 세 서비스를 동일하게 필요로 한다고 단정하지 않는다. 2026년 공급지표와 2013~2024년 이용지표를 직접 결합하지 않고, Q2에서는 2024년 이용자료와 가장 가까운 2024-07-16 공급 스냅숏만 조건부로 비교한다.

### 지표 3. 부족의 구성과 공급제약 가능성 보조 진단

### 지표 2-A. 목표충족률과 상대 자원부족도

```text
목표충족률_isr = min(1, 현재 공급수준_isr / 목표 공급수준_sr)
상대 자원부족도_isr = 1 - 목표충족률_isr
```

0은 목표충족, 1은 공급 없음 또는 최대 부족이다. 기관·인력·정원의 원 단위를 직접 비교하지 않고 상대부족도를 내림차순 정렬해 지역 내부 부족자원 순위를 산출한다. 기관 0은 `공급기반 미관측` 최우선 배타상태다.

접근성 상태는 `내부 기관 존재`, `내부 미관측·인접 접근 가능`, `내부 미관측·같은 도 접근 가능`, `접근 가능하지만 목표 미달`, `완전 접근공백`, `접근성 반영 목표충족`으로 구분한다.

### 지표 2-B. 지원 시급성

지원 시급성은 지역취약성·수요압력·접근성 반영 공급부족·접근성 불리·완전 접근공백의 결합이다.

```text
지원시급성_i
= w_v×지역취약성_i
+ w_d×수요압력_i
+ w_l×접근성반영부족_i
+ w_a×접근성불리_i
+ w_z×완전접근공백_i
```

요청서의 `-` 표기는 항목 구분으로 해석해, 값이 클수록 시급하도록 정규화된 위험요소를 가산한다. 기본 가중치와 민감도 범위는 설정에 기록하며 모두 공식값이 아닌 사용자 입력값이다. 종합점수는 순위 탐색용이지 실제 필요량·비용이 아니다.

| 유형 | 계산 규칙 |
| --- | --- |
| 공급기반 미관측 | `기관 수 = 0` |
| 상대적 기관 저공급 후보 | `기관 공급률 < 도 소속 군의 서비스별 제1사분위수` |
| 상대적 인력 저수준 후보 | `기관 수 > 0`이고 `핵심인력 공급률 < 서비스별 제1사분위수` |
| 상대적 정원 저수준 후보 | 주야간보호에서 `기관 수 > 0`이고 `정원 공급률 < 서비스별 제1사분위수` |
| 구조적 인력 공급제약 후보 | `기관 수 > 0`인 군의 기관 공급률-핵심인력 공급률 회귀모형에서 표준화 잔차 하위 20% |
| 구조적 정원 공급제약 후보 | 주야간보호 `기관 수 > 0`인 군의 기관 공급률-정원 공급률 회귀모형에서 표준화 잔차 하위 20% |
| 이용·연계 확인 필요 | 2024년 비교에서 `기관 공급률 ≥ 중앙값`이고 `연간 이용자 또는 제공일수 지표 < 제1사분위수` |
| 복합 부족 구성 | 위 부족 요소 조건 중 2개 이상 |
| 상대적 안정 | 설정한 모든 탐색적 공급수준 기준 충족 |

여기서 제1사분위수는 분석질문 Q1과 혼동하지 않도록 `제1사분위수`로 표기한다. 이는 공식 부족기준이 아니라 농촌 군 내부의 상대적 현장확인 기준이다.

서비스별 잔차모형은 다음과 같다.

```text
핵심인력 공급률_i = β0 + β1 × 기관 공급률_i + ε_i
주야간보호 정원 공급률_i = β0 + β1 × 기관 공급률_i + ε_i
```

부족 구성의 보조 분류는 다음 순서로 수행한다.

1. 기관 수가 0이면 `공급기반 미관측`으로 먼저 분류하고 잔차분석에서 제외한다.
2. 기관이 존재하면서 공급률이 제1사분위수 미만이면 `저수준 후보`로 분류한다.
3. 기관이 존재하면서 서비스별 표준화 잔차가 하위 20%이면 `구조적 공급제약 후보`로 분류한다.
4. 저수준과 구조적 공급제약 조건을 모두 충족하면 `우선 확인 공급제약`으로 분류한다.
5. 공급기능 기준을 충족하지만 같은 2024년 이용지표가 낮으면 `이용·연계 확인 필요`로 분류한다.
6. 기관이 존재하는 지역에서 서로 다른 요소의 조건을 두 개 이상 충족하면 `복합 부족 구성`으로 표시한다.
7. 위 조건을 충족하지 않으면 `상대적 안정`으로 분류한다.

공급기반 미관측은 최우선 배타적 유형이다. 기관 0으로 인해 인력·정원도 0인 경우 이를 별도의 인력·정원 공급제약이나 복합 부족 구성으로 중복 계산하지 않는다.

유사군 쌍은 동일 군이 여러 쌍에 포함되어 서로 독립적이지 않으므로 군 쌍 수를 표본 수로 간주한 유의성 검정을 하지 않는다. 제공역량 절대차이의 중앙값·사분위수와 5%·10%·20% 기준 변화에 따른 안정성만 제시한다. 각 군에 기관 공급률이 가장 가까운 한 군을 연결한 최근접 유사군 비교를 보조분석으로 둔다. 2026년 현재 부족의 구성은 기관·신고인력·정원으로 판단하고, 이용·연계 가능성은 2024년 공급 스냅숏과 연간 이용자료를 연결한 근사적 보조분석으로만 판단한다.

### 지표 4. 자원배치 시뮬레이션 성과

```text
배치 후 공급률 = (현재 자원 + 추가 자원) ÷ 인정자 수 × 1,000
목표 미달지역 수 = 배치 후 공급률이 사전 설정한 탐색 목표 미만인 군의 수
총 추가 필요량 = 동일 서비스×자원유형 안의 지역별 정수형 추가 필요량 합계
전략별 공급부족 개선량 = 배치 전 총 추가 필요량−배치 후 총 추가 필요량
지역 간 IQR = 배치 후 공급률 Q3−Q1
추가 자원 1단위당 부족량 감소 = 동일 서비스×자원유형의 전략별 공급부족 개선량 ÷ 실제 배치 자원 수
```

기본 탐색 목표는 `도 소속 76개 군의 서비스·자원유형별 중앙값`으로 고정한다. 도 소속 군의 제1사분위수, 전국 시군구 참고값과 사용자가 지정한 정책 입력값은 목표기준 민감도 분석에 사용한다. 본 연구의 목표기준은 공식 부족 또는 적정 기준이 아니라 전략 간 결과를 비교하기 위한 탐색적 시뮬레이션 기준이다. 기관·인력·정원은 합치지 않고 서비스·자원별로 별도 시뮬레이션한다. 전략별 공급부족 개선량과 자원 1단위당 부족량 감소도 같은 서비스×자원유형 시나리오 안에서만 비교한다.

### 5.3 시뮬레이션

#### 수동 변경과 스트레스 테스트

```text
추가: ΔS_isr > 0
감축: ΔS_isr < 0
동일 자원 이전: Σ_i ΔS_isr = 0
순증 배치: Σ_i ΔS_isr = B_sr
```

기관 추가·삭제, 인력 추가·감축, 정원 추가·축소, 지역 간 동일자원 이전, 기관 폐업·인력유출·정원축소와 특정 지역/도 단위 충격을 지원한다. 변경 후 접근권역의 유효공급도 모두 재계산한다.

| 서비스 | 별도 자원 단위 |
| --- | --- |
| 방문요양 | 기관 또는 요양보호사 |
| 방문간호 | 기관 또는 간호인력 |
| 주야간보호 | 기관·정원 또는 핵심인력 |

서비스와 자원유형별로 동일 총량을 별도로 배치하며, 기관 1개와 인력 1명 또는 정원 1명을 동일한 자원으로 간주하지 않는다. 비용자료가 없으므로 서비스 간 비용효율은 비교하지 않는다.

#### 배치전략 알고리즘

| 전략 | 재현 가능한 배치규칙 |
| --- | --- |
| 수요비례 | `지역 인정자 수 ÷ 전체 대상지역 인정자 수`로 비례 할당량을 계산하고 최대잔여법으로 정수 배분 |
| 공급부족량 우선 | 자원유형별 정수형 추가 필요량이 가장 큰 지역에 1단위를 배치하고 잔여 필요량을 다시 계산하는 과정을 반복 |
| 기관 미관측 우선 | 기관 0개 지역에 1개씩 우선 배치한 뒤 남은 기관 자원을 정수형 추가 필요량 순으로 반복 배치 |
| 지역취약성 우선 | 시뮬레이션용 취약성 배치점수가 높은 지역 → 인정자 수 → 지역코드 순 |
| 부족구성 맞춤형 | 기관 부족에는 기관, 인력 부족에는 핵심인력, 정원 부족에는 주야간보호 정원을 선택. 이용연계 확인 지역은 공급 추가 대신 현장연계 검토로 표시 |

Q5-B는 동일 조건에서 `어디에 배치할지` 비교하며, Q5-C는 기관·인력·정원 중 `무엇을 배치할지` 선택한다. Q5-C는 조건이 달라 Q5-B와 같은 순위표에서 직접 비교하지 않는다.

#### Q5-C 자원유형별 총량 제약

Q5-C는 비용 최적화가 아니라 사전에 설정한 자원유형별 최대 총량 안에서 실행한다.

- 기관 최대 총량: `B_institution`(기본값 5개)
- 핵심인력 최대 총량: `B_staff`(기본값 50명)
- 주야간보호 정원 최대 총량: `B_capacity`(기본값 100명)

기관·핵심인력·정원의 총량은 서로 합산하지 않는다. 기본값은 공식 자원량이 아닌 탐색적 정책 입력값이며, 자원유형별 총량을 변화시킨 민감도 분석을 수행한다. 비용자료가 확보되기 전까지 Q4-B를 동일예산 최적화 결과로 해석하지 않는다.

수요비례 전략의 정수 자원은 최대잔여법으로 배분한다. 먼저 인정자 비중으로 초기 비례할당량을 계산하고 정수화하되, 지역별 배정량은 해당 지역의 정수형 추가 필요량과 배치상한을 넘지 않는다. 상한 때문에 생긴 초과분은 잔여 필요량이 있는 지역만을 대상으로 비중을 다시 계산해 최대잔여법으로 재배분한다. 이 과정을 배치 가능한 자원이 없거나 모든 필요량이 충족될 때까지 반복하며, 이후 남은 자원은 `미배치 자원`으로 기록한다. 초과배치를 허용하는 순수 수요비례 방식은 별도 민감도 분석으로만 실행한다. 잔여가 같으면 인정자 수가 큰 지역, 이후 지역코드 오름차순으로 정한다. 다른 순위형 전략도 마지막 동률은 인정자 수와 지역코드 순으로 처리한다.

##### 공급부족량 우선 반복 배치규칙

1. 해당 서비스×자원유형에서 정수형 추가 필요량이 가장 큰 지역을 선택한다.
2. 자원 1단위를 배치하고 해당 지역의 잔여 정수형 추가 필요량을 다시 계산한다.
3. 잔여 필요량이 0이면 다음 지역으로 이동한다.
4. 필요량이 같으면 인정자 수가 큰 지역, 이후 지역코드 오름차순으로 정한다.
5. 모든 지역의 필요량이 0이 된 후 남은 자원은 기본분석에서 `미배치 자원`으로 기록한다.
6. 목표 초과배치는 이를 허용하는 별도 민감도 시나리오에서만 실행한다.

##### 기관 미관측 우선 반복 배치규칙

1. 기관이 0개인 지역에 기관 1개씩 우선 배치한다.
2. 기관 0개 지역이 모두 해소된 뒤 남은 기관 자원은 기관의 정수형 추가 필요량이 큰 지역 순으로 1단위씩 배치한다.
3. 해당 지역의 필요량이 충족되면 다음 지역으로 이동한다.
4. 필요량이 같으면 인정자 수가 큰 지역, 이후 지역코드 오름차순으로 정한다.
5. 모든 필요량이 충족된 후 남은 자원은 `미배치 자원`으로 기록한다.

##### 지역취약성 우선 반복 배치규칙

1. 잔여 정수형 추가 필요량이 있고 배치상한을 넘지 않는 적격 후보지역만 추출한다.
2. 핵심인력은 기존 기관이 있는 지역, 정원은 기존 기관이 있거나 동일 종합 시나리오에서 기관 신규배치가 선행된 지역만 적격으로 둔다.
3. 취약성 배치점수, 인정자 수, 지역코드 순으로 후보를 정렬한다.
4. 가장 높은 순위 지역에 자원 1단위를 배치한다.
5. 잔여 필요량·배치상한·기관 존재 조건을 갱신하고 더 이상 적격하지 않은 지역을 제외한다.
6. 갱신된 후보 순위를 순환하며 1단위씩 반복 배치한다.
7. 모든 후보의 필요량이 충족되거나 적격 후보가 없으면 남은 자원은 `미배치 자원`으로 기록한다.

#### 전략별 적용 가능한 자원유형

| 전략 | 기관 | 핵심인력 | 주야간보호 정원 | 비고 |
| --- | --- | --- | --- | --- |
| 수요비례 | 적용 | 적용 | 적용 | 기본 위치전략 |
| 공급부족량 우선 | 적용 | 적용 | 적용 | 기본 위치전략 |
| 기관 미관측 우선 | 적용 | 미적용 | 미적용 | 기관 자원 시나리오 전용 |
| 지역취약성 우선 | 적용 | 조건부 적용 | 조건부 적용 | 기존 공급기반 또는 기관 신규배치 조건 |
| 부족구성 맞춤형 | 선택 | 선택 | 선택 | 보조 종합 시나리오 |

지원 시급성 우선을 추가한다. 기관은 수요비례·부족량·기관 미관측·지역취약성·지원 시급성 5개, 핵심인력·정원은 기관 미관측을 제외한 4개 전략을 비교한다.

Q3의 관련성 분석에서는 취약성 지표를 각각 독립적으로 사용한다. 다만 Q4-A의 지역취약성 우선 전략에는 배치순서를 정하기 위한 별도의 시뮬레이션용 지수를 사용한다.

```text
취약성 배치점수_i
= w1 × z(고령화율_i)
+ w2 × z(고령 1인세대 부담지표_i)
```

표준화는 도 소속 76개 군 내부 평균과 표준편차를 사용하는 z-score로 고정한다. 기본 가중치는 `w1=0.5`, `w2=0.5`이며 `0.7/0.3`, `0.3/0.7`, 각 단일지표 사용을 민감도 분석한다. 이 점수는 공식 취약성 지수나 정책효과 지표가 아니라 전략 비교를 위한 입력 규칙이다.

#### 시뮬레이션 제약조건

- 자원은 음수가 될 수 없으며 기관·인력·정원은 정수로 배치한다.
- 기관이 없는 지역에는 인력만 단독 배치하지 않는다.
- 주야간보호 정원은 기존 기관이 있거나 동일 종합 시나리오에서 기관 신규배치가 선행된 경우에만 늘린다.
- 기관 미관측 우선전략은 기관 자원 시나리오에만 적용한다.
- 기본 위치전략끼리 비교할 때는 같은 서비스·자원유형·총량·목표기준·배치상한을 사용한다.
- 기본 배치상한은 군당 기관 2개·핵심인력 10명·주야간보호 정원 20명으로 설정한다.
- 배치상한 없음과 시나리오 총량의 20%·40%·60%를 상한으로 적용한 민감도 분석을 수행한다.
- 인접지역 자원공유는 기본모형에 합산하지 않고 별도 시나리오로 분리한다.
- 추가 자원 총량, 탐색 목표, 76개·82개 군 범위와 배치 상한을 바꾸어 결과의 안정성을 확인한다.

배치상한은 실제 설치 가능량을 의미하지 않고 자원의 과도한 지역 집중을 제한하기 위한 탐색적 시뮬레이션 입력값이다.

#### 방향성·보존 불변조건

- 추가 시 동일 자원 공급수준은 감소하지 않고 공급격차는 증가하지 않는다.
- 감축 시 동일 자원 공급수준은 증가하지 않고 공급격차는 감소하지 않는다.
- 총량고정 이전의 변경량 합계는 0이다.
- 모든 자원량은 0 이상 정수다.
- 기관 없는 지역에 인력만, 주야간보호기관 없는 지역에 정원만 단독 확충하지 않는다.
- 목표는 실행 중 고정하고 모든 전략에 같은 기준선·제약을 적용한다.

#### 목표기준 고정 원칙

모든 전략의 목표 공급수준은 배치 전 기준선 자료에서 한 번 계산해 고정한다. 배치 후 공급분포를 이용해 목표기준을 재계산하지 않는다. 민감도 분석도 각 반복에서 `목표 시나리오 선택 → 배치 전 목표값 고정 → 모든 비교전략에 동일 목표 적용` 순서를 지킨다.

#### 성과지표의 우선순위

| 구분 | 지표 |
| --- | --- |
| 1차 | 총 연속형 공급격차 감소, 목표 미달지역 수 감소, 기관 미관측지역 수 감소, 자원 1단위당 연속형 공급격차 감소, 수혜수요 규모, 하위 10% 공급수준 개선, 미배치 자원 수 |
| 2차 | 최저 공급수준, 제1사분위수, IQR, 변동계수, Gini 또는 기타 지역격차, 개선이 없는 지역 수 |

격차 감소만으로 전략을 평가하지 않는다. 낮은 수준에서 공급이 비슷해지는 경우를 구분하기 위해 최저 공급수준과 미충족지역 수를 반드시 함께 본다. 기관 0개 지역이 남으면 최솟값이 계속 0일 수 있으므로 하위 10% 평균 공급수준과 기관 0 해소지역 수도 함께 제시한다.

| 지표 | 개선 방향 |
| --- | --- |
| 총 연속형 공급격차·총 정수형 추가 필요량 | 감소 |
| 목표 미달지역·기관 미관측지역 수 | 감소 |
| 하위 10%·최저 공급수준 | 증가 |
| IQR·Gini | 일반적으로 감소 |
| 수혜수요 규모 | 증가가 반드시 형평성 우위를 뜻하지 않음 |
| 미배치 자원 | 제약조건과 필요량 충족 여부를 함께 해석 |

시뮬레이션 결과표에는 입력 자원 총량, 실제 배치 자원 수와 미배치 자원 수를 함께 기록한다. 정수형 추가 필요량 감소/배치량은 적격 배치에서 거의 1이 될 수 있으므로 보조지표로 두고, 연속형 공급격차 감소/배치량·목표 미달지역 해소 수/배치량·수혜 인정자 수/배치량·하위 10% 공급수준 증가/배치량을 함께 제시한다. 모든 지표는 동일한 서비스×자원유형 안에서만 산출하며 서로 다른 단위의 기관·인력·정원을 합산하지 않는다.

추가 결과는 상대부족도·부족자원 1순위·시급성 점수/순위 변화, 개선/악화지역 수, 목표충족↔미달 전환, 이전 원지역 손실·수혜지역 이득, 총량 보존, 시급지역 상위10 일치율과 순위 안정성이다. 접근성 시나리오는 직접/간접 수혜·악화지역, 완전 접근공백 증감, 유효공급 총격차 변화와 접근권역 순개선 지역 수도 제시한다.

#### Q2 회귀잔차 강건성 검사

기본 OLS 잔차분류 전에 산점도와 LOESS, 잔차-적합값, 영향점과 이분산을 확인한다. 강건회귀 또는 순위회귀 기반 잔차분류를 민감도 분석하고 기본분류와 후보지역 일치율을 제시한다. 잔차 하위 20%에 해당하는 실제 후보 군 수도 서비스별로 함께 보고한다.

강건회귀에서도 반복적으로 잔차 하위에 나타나는 지역을 우선 확인 후보로 해석한다. 구현 제약으로 강건회귀를 사용할 수 없으면 로그변환 또는 순위기반 잔차 결과를 최소 민감도로 제시하며, 어느 방법을 사용했는지 실행설정에 기록한다.

## 5.4 실행설정 고정

분석설계의 입력값은 코드에 직접 고정하지 않고 `03_데이터/config/statistical_config.json` 또는 별도 시뮬레이션 설정파일에 기록한다.

| 설정 | 주분석 | 민감도 |
| --- | --- | --- |
| 목표기준 | 배치 전 중앙값 | 제1사분위수·전국 참고값·정책입력값 |
| 기관 총량 | 5 | 1·3·5·10 |
| 핵심인력 총량 | 50 | 10·20·50 |
| 정원 총량 | 100 | 20·50·100 |
| 군당 배치상한 | 기관 2·인력 10·정원 20 | 낮음·기본·높음·없음 |
| 취약성 가중치 | 0.5/0.5 | 0.7/0.3·0.3/0.7·단일지표 |
| 지역범위 | 76개 군 | 82개 군 |
| 수요 | 인정자 중앙값 | 인정자 하한·상한·서비스별 시나리오 |

Gini 계산식, 하위 10%에 포함할 관측 수와 소수점 처리, 정수 총량의 반올림 규칙도 설정파일과 실행결과의 `run_config`에 함께 저장한다. 설계 입력값을 바꾸면 설정 버전과 변경 이유를 기록한다.

## 6. 선행연구 근거

- 김세진·김혜수(2021)는 65세 이상·85세 이상·1–3등급 인정자를 수요로, 시설 수·정원을 공급으로 구분해 시나리오별 형평성과 공간상관성을 분석했다.
- 맹진영(2017)은 방문요양·방문간호가 농촌보다 도시지역에 집중되고 방문간호의 불평등이 상대적으로 크다고 보고했다.
- 유재언(2015)은 해당 지역뿐 아니라 인접지역 공급과 대기수요를 함께 고려할 필요성을 제시했다.
- 농촌 장기요양 연구는 낮은 수익성·인력확보·이동거리 문제 때문에 단순 기관 확충 외의 지원이 필요하다고 지적한다.

## 9. 재현성·한계와 최종 결론
