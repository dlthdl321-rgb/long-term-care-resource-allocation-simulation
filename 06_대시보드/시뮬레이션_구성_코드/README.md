# 시뮬레이션 구성 코드

대시보드의 화면 표현과 분리해 재사용하는 시뮬레이션 규칙을 모은다.

- `field-support.ts`: 현장용 자동요약, 행동 검토문구, 3단계 탐색목표, 사전 시나리오, 결과 신뢰 표시와 비교 계산
- 화면 렌더링과 상태관리는 `app/page.tsx`
- 기준선·접근성·배치 결과 데이터는 `public/data`
- 이 폴더의 계산은 정책 권고나 인과효과 추정이 아니라 공개자료와 사용자 조건에 따른 결정적 비교다.

기관·서비스 제공인력·정원은 단위가 다르므로 서로 합산하지 않는다. 목표는 76개 군 분포를 이용한 탐색 기준이며 법정 배치기준이 아니다.
