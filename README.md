# 돌봄자원 랩

> 도 소속 76개 군의 장기요양 공급격차를 진단하고, 동일한 자원을 서로 다른 기준으로 배치했을 때의 변화를 비교하는 공공데이터 기반 의사결정 지원 프로젝트

[Live Dashboard](https://dlthdl321-rgb.github.io/) · [Case Study](CASE_STUDY.md) · [분석방법론](02_분석보고서/01_분석방법론.md) · [재현 안내](04_분석코드/README.md)

![돌봄자원 랩 대표 화면](06_대시보드/public/og.png)

## 해결하려는 문제

군 단위 장기요양 공급을 기관 수 하나로 판단하면 서비스별 제공역량과 지역 격차를 놓치기 쉽습니다. 이 프로젝트는 방문요양·방문간호·주야간보호의 기관·핵심인력·정원을 분리해 진단하고, 제한된 추가 자원을 어디에 우선 배치할지 정책목표별로 비교합니다. 결과는 설치 확정안이 아니라 현장검토 후보와 전략의 트레이드오프입니다.

## 분석 범위

- 대상: 도 소속 농촌 군 76곳
- 서비스: 방문요양, 방문간호, 주야간보호
- 수요: 장기요양 인정자 기반 공통 잠재수요
- 공급: 서비스별 기관(개소), 핵심인력(명), 주야간보호 정원(명)
- 기준시점: 수요 2026년 5월, 공급·인구 2026년 6월
- 분석 단위: 군 × 서비스 × 자원유형

## 핵심 결과

1. 방문간호기관은 공개자료상 76개 군 중 28곳에서 관측되지 않았습니다. 이는 실제 기관 부재를 확정하는 표현이 아닙니다.
2. 방문간호기관 5개소 대표 실행에서 수요규모 우선전략의 배치 대상지역 잠재수요 합계는 18,193명으로 가장 컸습니다. 기관 미관측 우선전략은 기관 미관측 상태 5곳을 계산상 해소하고, 해당 분석축의 연속형 공급격차를 4.931개소 줄였습니다.
3. 고령화율과 고령 1인세대 부담만으로 공급부족을 단정할 통계적 근거는 확인되지 않았습니다. 따라서 서비스별 공급격차·수요압력·접근공백을 함께 봅니다.

같은 총량에서도 수요 대응, 최소서비스 기반, 취약지역 우선이라는 목표에 따라 유리한 전략이 달라집니다. 하나의 ‘최적 순위’를 제시하지 않는 것이 이 분석의 핵심 판단입니다.

## 만든 결과물

- 76개 군의 서비스·자원별 공급병목 진단
- 동일 조건의 자원배치 전략 비교와 민감도 분석
- 지역 비교, What-if, 자동배치, 외부공급, 품질·한계를 연결한 React 대시보드
- 입력 데이터 계보, 품질검사, 통계·시뮬레이션 재현 코드

## 해석 한계

- 잠재수요는 인정자 기반 공통 분모이며 서비스별 실제 필요인원이나 실제 미충족수요가 아닙니다.
- 신고 인력은 실제 FTE·운영시간·신규접수 여력을 뜻하지 않습니다.
- 기관 미관측은 원자료의 관측 상태이며 실제 기관 부재와 같지 않습니다.
- 시뮬레이션은 정해진 입력과 규칙에 따른 계산 결과로 정책의 인과효과를 증명하지 않습니다.
- 실제 결정 전 비용, 설치 가능성, 대기, 이동시간과 현장자료 검증이 필요합니다.
