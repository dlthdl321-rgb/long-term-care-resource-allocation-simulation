# Long-Term Care Resource Allocation Simulation

농촌 군 지역의 재가 장기요양서비스 기능공백과 공급병목을 진단하고, 제한된 추가 자원의 배치 방식에 따른 지역 격차 변화를 비교하는 데이터 분석 프로젝트입니다.

## 연구 질문

1. 도 소속 군에서 고령화율과 고령 1인세대 비율이 높을수록 장기요양 인정자 1,000명당 방문요양·방문간호·주야간보호의 기관 수와 핵심 인력 수가 낮은가?
2. 기관 공급수준이 유사한 농촌 군 사이에서 핵심 인력, 주야간보호 정원, 실제 이용자 수와 제공일수에 차이가 있는가?
3. 동일한 추가 자원을 배치할 때 수요비례, 공급공백 우선, 지역취약성 우선, 병목 맞춤형 방식 중 어느 방식이 최소기능 미충족지역 수와 공급격차를 가장 많이 줄이는가?

## 분석 범위

- 대상: 도 소속 농촌 군 행정구역
- 서비스: 방문요양, 방문간호, 주야간보호
- 수요: 고령인구, 고령 1인세대, 장기요양 인정자
- 공급·운영: 기관, 핵심 인력, 정원, 이용자, 제공일수
- 방법: 기술통계, 지역 간 비교, 상관·회귀 기반 추론통계, 자원배치 규칙별 계산 시뮬레이션

현재 시뮬레이션은 공개 집계자료를 이용한 정책 대안 비교입니다. 실제 자원 확충의 인과효과나 개인의 건강·삶의 질 개선 효과를 직접 증명하지 않습니다.

## 실행

```bash
python -m venv .venv
pip install -r requirements.txt
python "04_분석코드/check_preanalysis_readiness.py"
python "04_분석코드/analyze_ltci_resource_allocation.py"
```

일부 수집 스크립트는 공공데이터포털 또는 KOSIS 인증키를 환경변수로 요구합니다. 인증키는 저장소에 포함하지 않습니다.

## 공개 원칙

- API 인증키, `.env`, 가상환경은 제외했습니다.
- 용량이 큰 원본 응답 파일은 제외하고 전처리·분석용 자료와 재현 코드를 제공합니다.
- 선행연구 PDF 원문은 저작권 보호를 위해 제외하고 서지정보와 검토표만 제공합니다.
- 공개자료의 이용조건과 최신성은 각 제공기관의 원문 페이지에서 다시 확인해야 합니다.
